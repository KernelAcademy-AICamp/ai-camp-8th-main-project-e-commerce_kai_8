# 후속 메모 — 컬러웨이 결속 검색 (검색 측 선행분 완료 후)

- 작성일: 2026-08-07

- 관련: [실행 계획](../superpowers/plans/2026-08-07-colorway-print-search-baseline.md) · [착수 결정 기록](2026-08-07-colorway-search-kickoff-decisions.md) · [설계](2026-08-07-colorway-search-optional-llm-design.md)

## 완료된 것 (검색 측 선행분)

- 어휘 계약 단일 소스(`colorway-vocab.ts`, 버전 해시 포함)
- 결정적 해석기(`colorway-interpret.ts`) — 골든셋 27건 전건 통과, 소비 span 계약
- 결속 계획 컴파일(`colorway-plan.ts`) + 기준 판정기(`colorway-evaluate.ts`) — 진리표 8케이스
- jsonb 실행 어댑터(`colorway-adapter.ts`) — superset 사전필터 + 기준 판정기 재판정, 실데이터 스모크 4건 통과
- `search_goods` 뷰에 `base_colors`·`prints` 노출(마이그레이션 `20260807120000`, 원격 적용됨)
- 통합 지점(`colorway-lane.ts` + route) — **`SEARCH_COLORWAY_LANE` 기본 꺼짐**, 4종 검증(꺼짐 미호출·켜짐 계획 전달·소비 표현 중복 적용 금지·실행 실패 폴백)

## 스위치 켜기 전환 조건 (충족 전 `on` 금지)

1. **데이터 커버리지**: 라벨 완료 상품이 검색 카테고리에서 의미 있는 비율(팀 합의 필요 — 현재 12/3658건). 켜면 컬러웨이 조건 검색이 "라벨된 상품만"으로 좁아지므로, 라벨 부족 상태에서 켜면 정당한 상품이 대량 누락된다.
2. **교차 매칭 실데이터 검증**: 다컬러웨이+프린팅 상품(잉크색이 컬러웨이별로 다른 케이스)이 적재된 뒤 `COLORWAY_LIVE=1` 스모크에 해당 케이스 추가·통과.
3. 켜기 전 프리뷰(develop)에서 `SEARCH_COLORWAY_LANE=on` 환경으로 대표 쿼리 수동 확인.

## 데이터 측 요청 (병행 중)

- **[미정 A] 라벨 provenance 3종 재도입** — jsonb 전환 때 빠진 라벨 시각·스키마 버전·프롬프트 버전. 재라벨링·골든셋 비교에 필요.
- **[미정 B] 커버리지 공백 배치** — 다컬러웨이+프린팅(최우선), 뒤/소매/전체 면, 없음·판독불가 상태, 무늬 전용(`sides=[]`) 객체.
- 참고: 무지 라벨 상품 일부(예: 1370888)는 `searchable=false`라 검색 뷰에 없음 — 라벨 대상 선정 시 searchable 여부 고려.

## 2차 출하선(LLM shadow) 착수 조건

- 1차 스위치 켜짐 운영이 안정된 뒤.
- 설계 §8 `SEARCH_LLM_MODE=off|shadow|on` — 이 스위치는 `SEARCH_COLORWAY_LANE`과 별개 축(결정 기록 D3).
- shadow 결과는 off와 완전 동일해야 하며, `QueryInterpretation` 검증(§9)부터 최소 구현.
- 미해결 표현 로그(`ColorwayLane.unresolved` — 현재 관측만)가 표현 사전 승격 후보의 입력이 된다.

## 보류 결정

- **서버측 검색 결과 캐시(§11 캐시 키는 정의됨)** — 정확도 안정화 후 도입 (2026-08-07 팀 결정: 테스트 단계에서 잘못된 해석 결과가 캐싱되면 수정 검증이 불편해짐. 설계 §11도 "캐시는 정확성 구조를 대신하지 않는다"라 명시). 도입 시점: 해석 규칙·모델·어휘 변경 빈도가 낮아진 뒤. 캐시 키에 어휘·프롬프트·모델 버전이 포함되므로 버전이 바뀌면 자동 무효화되는 구조는 이미 준비됨.

## 남은 기술 부채 (작음)

- route의 컬러웨이 실행은 결과 계산 후 별도 쿼리 1회(교집합 방식) — 라벨 커버리지가 커지면 본 쿼리에 사전필터를 합치는 최적화 여지.
- UI 해석 칩·관측/추론(observed/inferred) 구분 노출 — 스위치 켜기와 함께 별도 작업.
- `unresolved`·`external` 표현의 GA4/로그 수집 연결(승격 파이프라인 §7) — 미연결.
