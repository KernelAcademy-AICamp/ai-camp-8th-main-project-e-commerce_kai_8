# 사이즈 매핑 사전 (LLM 검색용 레퍼런스)
> 2026-07-30 · 무신사 정규화 부속. `size_std` 컬럼과 짝. 데이터(라벨 co-occurrence) 기반.

## 목적
사용자 자연어 사이즈("남성 M", "여성 44반", "105")를 **통일 척도 `size_std`(85~120, cm식)** 값으로 바꿔 검색하기 위한 규칙. LLM 프롬프트에 스키마와 함께 제공한다. **성별(`gender`)로 몸 차이를 구분**하므로 항상 성별과 함께 해석.

## 통일 척도 = cm식 숫자 (85~120)
상품의 모든 사이즈 표기는 `size_std`에 이 척도로 정규화되어 저장됨. 사용자 입력도 아래 표로 이 척도로 바꿔 매칭.

## 글자 → cm (남녀 공통, 데이터 확정)
| 글자 | cm |
|---|---|
| XS | 85 |
| S | 90 |
| M | 95 |
| L | 100 |
| XL | 105 |
| XXL = 2XL | 110 |
| XXXL = 3XL | 115 |
| 4XL | 120 |
- **XXL과 2XL은 같은 표현**(둘 다 110). 5XL→125, 6XL→130.
- 남성 데이터로 검증(M=95가 370회로 압도적). 여성 글자는 약간 낮게(S≈85) 쓰이기도 하나 인접 오차라 동일 표 사용.

## 여성 44체계 → cm (데이터: 55↔S, 66↔M, 77↔L)
| 44체계 | cm |
|---|---|
| 44 | 85 |
| 55 | 90 |
| 66 | 95 |
| 77 | 100 |
| 88 | 105 |
- **44반 = 44.5** → 통일 척도엔 딱 맞는 칸이 없어 **85로 흡수(base 44 기준)**. 즉 "44반" 검색 = "44반인 사람에게 맞는 XS/S(≈85~90)" 상품을 찾는 것. 정확한 반사이즈 필터는 통일 척도에선 불가(발견 제품엔 무방).
- 88/99는 cm(85~120)와 겹쳐 모호 → cm로 취급(그대로).

## LLM 해석 예
| 사용자 입력 | gender | → size_std 매칭 |
|---|---|---|
| "M 입어요" | 남성 | `95 = ANY(size_std)` |
| "95" | 남성 | `95 = ANY(size_std)` |
| "55" | 여성 | `90 = ANY(size_std)` |
| "44반" | 여성 | `85 = ANY(size_std)` (근처 XS/S) |
| "L" | 여성 | `100 = ANY(size_std)` |
| "105 입는데 좀 넉넉하게" | 남성 | `size_std && array[105,110]` |

## 주의
- 검색은 반드시 **`gender` 조건과 함께**(남 95 ≠ 여 95, 몸 다름).
- 프리사이즈(`size_free=true`)는 사이즈 무관 → 사이즈 필터에서 별도 처리.
- 통일은 정확도(교차 매칭)를 위한 것이고, 원본 표기는 `sizes`, 원본 숫자는 `size_numbers`, 글자는 `size_letters`에 그대로 보존됨.
