## ⚠️ 지표 해석 주의 (측정이 재는 것과 안 재는 것)

- 쿼리 골든셋 지표는 **"E2E 출력 누락률"** — 최종 응답 결과(≤300건)에 정답이 없는 비율이다. 하드필터 탈락·후보 1,000건 절단·랭킹 300건 절단이 뒤섞인 값이므로 **기준 3의 축별 누락률(임계 ≤5%)과 직접 비교할 수 없다**. 축별 원인 귀속 실측은 3a에서 QueryPlan 계측으로 한다.
- 색 precision은 **abstention 규약**: 추출을 시도한 항목만 분모(침묵=무오답 처리). 전부 침묵하는 추출기도 100%가 되는 규약이므로 **coverage(추출 시도율)·recall과 반드시 함께** 읽는다. 침묵이 정답인 unmapped 5건은 별도 "침묵 정확도"로 보고.

## 결과 (3회 평균, 괄호는 범위)

### 색 표현 매핑 — 현행 LLM baseline (기대값 있는 45건 + unmapped 5건)

| 지표 | 값 |
|---|---|
| precision(시도분, abstention 규약) | **36.9%** (35.9~37.8%) |
| coverage(추출 시도율) | 83.7% (**68.9~100%** — 회차 간 변동 큼, 시도 수 31·37·45) |
| recall | 48.5% (**43.7~56.5%**) |
| **침묵 정확도(unmapped 5건)** | **0.0%** — 침묵해야 할 표현 전부에서 3회 내내 색 추출 |

참고: 3a 사전의 게이트는 기준 2 precision ≥95%(골든셋 순수 함수 검증)다. 현행 LLM은 precision은 좁은 범위로 일관되게 낮고(±1%p), **무엇을 추출할지(coverage)는 회차마다 크게 흔들린다** — "같은 검색=같은 결과"가 성립하지 않는 두 번째 실증.

대표 병리(run1~3.jsonl에서 재검산 가능, 회차 표기):

- **일관 오류**: "곤색"→vocab 대량 덤핑(3회 모두 오답, 회차별 48·9·48색), "어두운 색"→다크\*+무관색 대량(3회 모두), "아이보리"→화이트(3회 일관 — 직접 표현 오매핑).
- **비결정 오류**: "먹색"→3회 모두 오답인데 매회 다른 계열(핑크계→핑크계→파랑계), "남색"→2회 침묵·1회 무관색(핑크·레드·라임), "크림색"→1회 침묵·2회 라이트\* 덤핑, "와인색"→1회 침묵·2회 라벤더.

| 정답 구분 | 누락(3회 평균) |

| metadata 갭 3개(카탈로그 메타 결함) | 2.0/3 — 색 OR로 우연 회수되는 1개 존재 |

- **함정 쿼리 색 오추출**: 회차당 평균 3.3개 쿼리에서 발생(q001·q005 신발색, q015 무지개, q028) — 오추출 색이 하드필터로 투입되며, 해당 쿼리들의 정답 누락이 **동반 관측**됐다. 단 q015·q028에는 제목 동의어 갭도 있어 누락의 단일 원인으로 단정하지 않는다(원인 귀속은 3a QueryPlan 계측).
- **정렬 해석**: 평균 2/3 — "제일 인기"(대화체)는 3회 모두 오답(relevance 2회·price_asc 1회 — 오답 값 자체도 요동), 명시적 "인기순"·"싼 순"은 정확.
- 잘 되는 것: 명시 단순 쿼리(셔링·블랙 오버핏 3만 이하·여성 슬림·폴리 남성 2만원대)는 회차 무관 만점 — 문제는 대화체·함정·계열 표현의 분산.
- browse 3건(q019~21)은 현행 failed — 3c 입구 분기 구현 전 예상 동작.

## 함의 (관측 기반 추정 — 단정 아님)

1. **3a 색 사전의 성공 기준이 정량화됨**: 결정적 사전은 골든셋 순수 함수 검증으로 precision 95%를 달성해야 하며, 현행 LLM(37%, abstention 관대 규약) 대비 구조적 우위가 요구 조건이다.
2. **flag-on(결정화 레인)의 기대 효과**: 함정 쿼리의 오추출 색은 전부 LLM 출처이므로 flag-on에서 하드 제거·소프트 강등된다 — **색 하드필터 유래의 소실 경로는 제거될 것으로 예상**된다. 단 제목 매칭·다른 조건·후보 절단에 의한 누락은 남을 수 있으므로 실제 개선 폭은 3a shadow 계측으로 확인한다.
3. **T0a 골든셋의 판별력 입증**: 함정·공백·계열·동의어 케이스가 실제 실패 지점을 정확히 짚었다(synonym·stopword 갭 전 회차 전멸 = 갭 표식의 예측 그대로).
