# 문제 검증 (Problem Validation)
> 유형: foundation · 2026-07-21 · 갱신 2026-07-30(무신사 프레임 재정립) · 방법: 5Why + 웹 리서치(실제 목소리) + 직접관찰

## 5Why (왜 못 찾나)
1. 왜 못 찾나? → 원하는 "백프린팅만 노란 + 기능성 + 내 사이즈" 티가 검색·필터로 안 걸림
2. 왜 안 걸리나? → 검색이 색을 **옷 전체**로만 인식, "프린팅색=노랑/바탕=흰" **조합**을 표현할 수단이 없음
3. 왜 조합이 안 되나? → 상품 데이터가 색·프린팅위치·소재·기능성 같은 **구조화된 속성**으로 존재하지 않음(제목·이미지에 파묻힘)
4. 왜 확인이 오래 걸리나? → 검색결과가 **대표 썸네일 1장**뿐 → 등판·소재·사이즈를 상품마다 상세페이지 들어가 확인
5. **근본 원인**: 상품이 "말로 조합해 검색할 수 있는 속성 데이터"로 구조화돼 있지 않고, 검색이 키워드 매칭에 머무름. → **속성 구조화 + 시맨틱(말로) 검색**이 해법.

## 5Why 재정립 — 무신사 프레임 (2026-07-30)
> 데이터 소스가 무신사로 전환(README D14)되면서 문제 무대를 "포털 검색 전반"에서 "무신사 내 발견"으로 좁혀 재정립. 위 원본 5Why는 히스토리로 유지.

1. 왜 무신사에서 못 찾나? → "흰 바탕 + 노란 백프린팅" 티가 검색·필터로 안 걸림
2. 왜? 54색 색상 필터까지 있는데? → 색 필터는 **상품 대표색 1개** 기준. 바탕색/프린팅색을 구분하는 축이 없고, 프린팅 위치(앞/뒤) 필터도 없음
3. 왜 그런 축이 없나? → 상품 속성이 **파는 사람 기준**(브랜드·카테고리·대표색)으로 구조화돼 있고, **찾는 사람의 언어**(바탕×프린팅색×위치 조합)로는 구조화돼 있지 않음
4. 왜 검색어로도 안 되나? → 검색이 상품명·브랜드 키워드 매칭 중심이라 "백프린팅만 노란" 같은 조합 질의를 속성으로 해석하지 못함
5. **근본 원인(재정의)**: 구조화가 "없어서"가 아니라 **구조화의 축이 사용자의 탐색 언어와 어긋나 있어서**. 상품·필터가 다 갖춰진 국내 최대 패션 플랫폼에서도 '보이는 것'(바탕색·프린팅색·위치·그래픽)의 축으로는 발견이 안 된다. → 해법은 동일하게 속성 태깅 + 말로 하는 조합 검색이되, 포지셔닝은 **"무신사 위에 발견 레이어를 얹는다"**로 선명해짐.

- **무신사 내 우회행동**(스냅 뒤지기·리뷰 사진 뒤지기·브랜드샵 순회): **추측(플래그)** — 사용자 인터뷰·웹 리서치로 보강 대상.

> **이 5Why에는 종목이 안 걸려 있다.** 근본 원인(구조화의 축 ≠ 탐색 언어)은 클라이밍이든 러닝이든 동일하게 성립하므로, 세그먼트 정의가 바뀌어도(클라이머 → D15 "등이 보이는 운동" → **D17 문제 축**: 프린팅 티를 '보이는 속성(바탕색×프린트색×위치)'으로 조합해 찾고 싶은데 못 찾는 사람) **문제 정의는 바뀌지 않는다.** 바뀐 것은 누구부터 만나느냐뿐.
>
> 다만 진입 트리거 가설 A("등판이 보인다")가 인터뷰에서 확인되면 5Why에 **한 겹을 더한다**: 왜 하필 등판이냐 → **운동 중 남에게 보이는 게 등판**이라서. 그리고 쇼핑몰은 등판을 대표컷으로 안 쓰므로, 이 사람들은 **구조적으로 상세페이지를 열 수밖에 없다**(4번 항목의 "확인이 오래 걸린다"가 특히 심한 이유). ⚠️ 트리거는 아직 **가설**이지 세그먼트를 정의하는 조건이 아니다(D17).

## 메타인지 업데이트

- **(7/30 추가) 이 정의가 틀렸다면 나타날 반증 신호**: ① 무신사 스냅·큐레이션·매거진으로 이미 충분히 발견된다 ② 인터뷰에서 사용자들이 조합 검색의 필요를 못 느낀다 ③ 무신사가 부위별 색 축을 자체 도입한다. 인터뷰에서 반증질문으로 확인할 것.
- **(7/31) ⚠️ 웹 검증이 트리거 근거를 흔들었고 → 세그먼트를 재정의했다(D15 → D17: 정의를 문제 축으로, 트리거는 인터뷰 검증 가설로 강등).**
  "튀는 색 장비에 옷을 맞춘다"는 트리거를 검증한 결과 **판정 (b) 소수 존재**(확증 33 : 반증 26)이고,
  종목별 신호는 **러닝 25 ≫ 골프 11 > 테니스 3 ≫ 클라이밍 1**이었다.
  **원래 타겟이던 클라이밍이 가장 약하다** — r/climbing은 r/10s보다 훨씬 큰 서브레딧인데 1건이고,
  신발 담론이 사실상 전부 핏·사이즈다. 반대로 러닝은 불편의 형태까지 구체적이다
  ("브랜드가 매칭되는 상의를 아예 안 만든다", "맞추려다 걍 딴거사야겠다").
  게다가 **테니스는 깔맞춤에 사회적 페널티**가 있다("full kit wanker"). → "스포츠 전반"으로 넓히면 신호가 희석된다.
  이 트리거를 굳이 세그먼트 정의로 쓴다면 "러너 전체"가 아니라 **"신발색에 옷을 맞추려는 러너"**로 좁혀야 하고,
  **그 크기는 이번 조사로 모른다**(빈도 비율 미측정). → **D17은 그 대신 정의를 문제 축으로 내리고 트리거는 인터뷰 검증 대상으로 두었다.** 상세: [voice-of-customer.md](voice-of-customer.md) 4번.
- **(7/30 추가, 7/31 D17 기준 갱신) 인터뷰 결과 해석 기준**: ① **"등판이 보여서 신경 쓴다"를 스스로 말하지 않으면** → 무너지는 건 축이 아니라 **트리거 가설 A**다(우리가 먼저 꺼내지 말고 자발 언급으로 확인). 축이 무너지는 조건은 따로다 — **조합검색 필요("색 분리"·"뭐라고 검색해야 할지 모름")를 아무도 자발 언급하지 않을 때**(PRD §11 Kill ③). ② **표본을 한 종목으로 고정하지 않는다**(D19 — 범위 = 스포츠 프린팅 티 전반). 다만 실제로 모이는 사람은 **연줄 모집 편의**로 정해지므로, 결과를 축 전체로 일반화하지 않는다. **인터뷰마다 종목을 기록하고 결과를 종목별로 쪼개 읽는다** — VoC가 "스포츠 전반으로 넓히면 신호가 희석된다"고 경고했기 때문이고, 그 대응은 표본을 좁히는 게 아니라 종목을 분해해 보는 것이다. ③ **굿즈(암장·박스 티) 수요가 압도적이면** 무신사 기성품으로는 못 푸는 문제 → 세그먼트 킬. 넓힌 게 아니라 흐린 게 되는 것이 이 조정의 실패 모드.
