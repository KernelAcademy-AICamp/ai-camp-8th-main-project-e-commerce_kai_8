## 현재 상태 (이번 루프에서 만든 것)

- **3-way 하이브리드 검색**: 의미(임베딩) + 어휘(제목 단어) + 구조화 속성을 pgvector RPC에서 합산 랭킹.
- LLM(Llama-3.1-8B)이 쿼리를 `intent`(속성) + `semanticQuery`(확장) + `keywords`(제목 단어)로 분해.
- 임베딩 = `nvidia/nv-embedqa-e5-v5`(1024차원), 상품 1,685개 백필 완료.
- 점수식: `score = 0.5·의미(cosine) + 0.4·어휘(제목 keyword ILIKE 비율) + 0.1·속성가점`.
- **골든 검증**: "홀로그램 느낌나는 티셔츠 찾아줘" → 상위 10개 전부 홀로그램 상품(이전 0개).

## Codex 리뷰 핵심 진단 (냉정 평가)

> "지금 구조는 최적이 아니라 **dense 임베딩의 한계를 어휘 가점으로 땜질한 하이브리드**다. 단, 땜질 방향은 맞다."

- 카탈로그가 동질적(전부 클라이밍 반팔 티) → 코사인이 0.30~0.31에 뭉침 = 임베딩이 상품을 잘 구분 못 함. "홀로그램"은 사실상 **어휘 축이 해결**(의미 점수 차 0.005 vs 어휘 0.4).
- 상품 속성 컬럼이 대부분 NULL → `w_attr=0.1`이 죽어 있음. LLM 쿼리 파싱은 현재 데이터에선 **과투자**.
- 임베딩 입력("제목+카테고리")이 너무 짧고 중복적 → dense는 보조축, 리터럴은 어휘가 맡아야.
- 고정 가중치 0.5/0.4/0.1은 세 축의 **분포 불일치**(sem 0.30대 좁은 구간 / lex 0~1 / attr≈0)로 부당.

## 백로그 (우선순위)

### P1 — 상품측 속성 추출 (가장 큰 레버)
- **무엇**: 제목·이미지에서 `base_color`, `print_color`, `print_position`, `graphic_type`, `functional`, `motif`/테마 태그를 채운다(현재 전부 NULL).
- **왜**: 이게 채워져야 `w_attr`가 살아나고, 색·성별·브랜드가 검색에 실제로 기여한다. LLM은 쿼리 파싱보다 **여기(오프라인 상품 태깅)** 에 먼저 투입하는 게 옳다.
- **효과**: "빨간색 반팔" 같은 색 쿼리가 그제서야 동작(현재는 base_color NULL이라 못 거름).

### P2 — 어휘 매칭을 pg_trgm / FTS로 교체
- **무엇**: 현재 `title ILIKE '%kw%'`(단순 substring 비율)을 `pg_trgm`(트라이그램 유사도) 또는 Postgres FTS(`to_tsvector`)로.
- **왜**: 띄어쓰기·오타·형태 변화·복합어에 약함. BM25에 가까운 어휘 신호가 필요.

### P2 — 랭킹 융합 재설계 (어휘 우선 + dense 타이브레이커)
- **무엇**: 고정 가중 합산 대신:
  - keyword/제목 매칭이 있으면 어휘 후보를 먼저 올림 → 어휘 동률에서 dense로 정렬
  - keyword가 없는 **추상 쿼리일 때만** dense 비중 확대
  - 세 축 점수를 분포에 맞게 정규화(현재 sem 0.30대 vs lex 0~1 불일치)
- **왜**: 지금은 숫자상 의미 0.5가 커 보여도 실제 승부는 어휘가 냄 → 의도를 점수식에 명시적으로.

### P3 — 임베딩 입력 풍부화
- **무엇**: "제목+카테고리"에 추출된 속성/태그를 합성 텍스트로 보강.
- **주의**: 아키텍처 B(자유텍스트만 임베딩) 원칙과 충돌 여지 — 속성을 임베딩에도 넣으면 어휘/속성 축과 이중 계산. 넣을지 여부를 A/B로 판단.

### P3 — 속성 완성 후 필터/prior 분리
- 색·성별·브랜드는 소프트 가점(boost)보다 **hard filter 또는 strong prior**로 분리(속성 데이터가 신뢰 가능해진 뒤).

### 유지보수 / 관찰성 (SDD 리뷰에서 미룬 항목)
- `mapSearchRow`(search-response.ts)와 `mapRowToTee`(supabase-tee-repository.ts)의 매핑 로직 중복 → 공통 매퍼 추출.
- `use-search-view-model.ts` 단위 테스트 부재(Task 8 브랜드 회귀를 못 잡았음) → RTL 훅 테스트 추가.
- `parseIntentLLM`/`embedQuery`의 조용한 실패(빈 catch)에 Sentry 계측 추가(운영 이슈 감지).
- `supabase-tee-repository.ts`의 `print_color` 잔여 스칼라 취급(이번 브랜치 밖, text[]로 정정 필요).

### 측정 (lean loop)
- 골든셋 확장(홀로그램·곰·고양이 외 다양한 테마·색·브랜드 쿼리) → 가중치·구조를 A/B로 튜닝.
- bge-m3(한국어 강) 재시도 — 현재 이 NVIDIA 계정에서 500(서빙 이슈). 살아나면 e5-v5와 비교.
