# MVP 계획 (MVP Plan) — 3×2주 린 루프
> 유형: living · 2026-07-21(개정) · 방법: Build-Measure-Learn 루프 ×3
> **이 프로젝트의 핵심 = "데이터로 의사결정하는 과정"을 보여주는 것.** 완성도 자랑이 아니라 매 루프 끝에 데이터→결정이 나오는 걸 증명한다.

## 한 줄
말로 조합 검색하고(색×프린팅위치·핏·기능성) 한눈에 비교하는 **프린팅 반팔티 발견 검색**. 첫 타겟은 **프린팅 티를 '보이는 속성(바탕색×프린트색×위치)'으로 조합 검색하고 싶은 사람**(D17). 범위는 **스포츠 프린팅 티셔츠 전반**이고 Loop1 모집도 종목 혼합(D19). 2주 루프로 만들고-재고-배우며 3회 반복.

## 전체 구조 (6주 = 2주 × 3)
```text
Loop 1 (W1-2) 가치검증 + 최소 자동추출 → 배포 → GA4+인터뷰 → 의사결정
Loop 2 (W3-4) Loop1 데이터가 가리키는 곳에 투자        → 측정 → 의사결정
Loop 3 (W5-6) 정밀화·전환·확장 + 최종 산출물          → 측정 → 회고
```
매 루프 종료 시 [iterate-log.md](iterate-log.md)에 회고·배운것·피봇/지속 결정 기록.

## Loop 1 (W1-2) — "이 검색 방식이 쓸만한가?"
**목표 가설**: H1(추출 정확도 임계 달성) · H2(자연어 조합 검색이 탐색을 실제로 줄인다)
**최소 자동추출**: Supabase 적재 전체(1,685행, 선별 풀)에서 프린팅티 **50~100개**를 선별(D14) — 이 50~100개가 **Loop1에서 검증·노출되는 평가 집합**(정확도·검색 지표의 분모) → 상품 이미지를 **비전 LLM 단일 호출→JSON**(바탕색/프린팅색/프린팅위치/그래픽유형/핏/소재추정)으로 속성화 — **Loop1 추출 계약은 비전 LLM 단독이고, OpenCV/OCR 하이브리드는 Loop2/P1 정밀화에서만 붙인다**(D12 · [data-feasibility §5](../foundation/data-feasibility.md)) → 사람 샘플 검증(속성별 정확도) → 임계 미달 속성은 검색서 숨김.
**빌드**: 자연어 쿼리→LLM 파싱→속성 랭킹 · 결과 리스트 · 상세 · **상품 페이지 이동(구매 진입) 링크** · **GA4 계측** · Vercel 배포.
**측정**: 검색 사용·no-result율·결과 클릭·**구매 진입 클릭**·세션시간(→[metrics.md](metrics.md)) + 사용자 인터뷰 3~5(종목 혼합·최소 1명 클라이머).
**의사결정 게이트**: 정확도 임계 통과? 검색이 실제로 원하는 걸 찾아주나? → Loop 2 투자처 결정.

| 팀원 | Loop 1 |
|---|---|
| 개발 | 무신사 수집·적재 + 비전LLM 추출 + 검색/파싱 + 프론트(Next+shadcn) + GA4 + 배포 |
| 카탈로그 | 속성 스키마 + 라벨 기준 + 카탈로그 50~100 큐레이션 |
| 시각속성 검증 | 색·프린팅·그래픽 샘플 정확도 검증 |
| 감각속성·인터뷰 | 소재·기능성·느낌 태그 검증 + 사용자 인터뷰 진행(3~5, 종목 혼합 — 종목 기록 필수) |

## Loop 2 (W3-4) — "데이터가 가리키는 곳에 투자"
**입력 = Loop1 데이터.** 예: no-result 많음 → **카탈로그 확장(200~500)**; 특정 속성 오검색 → **추출 개선**(색 분리에 OpenCV 보조/세그멘테이션·OCR 추가); 쿼리 실패 → **파싱 개선**; 상세는 가나 구매 진입 안 함 → **상세/신뢰 정보 개선** or **신발색 매칭 훅(P1)**.
**측정·인터뷰 반복 → 의사결정 게이트.**

## Loop 3 (W5-6) — "정밀화·전환·확장 + 마감"
전환(구매 진입·구매의향) 개선 · (신뢰도 되면)2000 확장 시도 · 감각/리뷰 소규모 실험 · **최종 인사이트 보고서(3루프 데이터→의사결정 서사)** · 발표자료 · PRD 최종 · 랜딩.

## 기능 스코프
- **P0(Loop1)**: 최소 자동추출 파이프라인 · 속성 스키마 · 검증 루프 · 자연어 검색 · 결과 리스트·상세 · 구매 진입(outbound) 링크 · GA4
- **P1(Loop2~3)**: 카탈로그 확장 · 추출 정밀화 · 신발색 매칭 훅 · 필터 고도화
- **P2(v2+)**: 리뷰 본격 · 비주얼 유사검색 · 대화형 재질문 · 확장 종목(러닝·라이딩·스케이트/서핑) · 장비색 매칭 훅

## "불편할 정도로" 줄인 것
- 실결제·실장바구니 없음 → **상품 페이지로 이동(구매 진입) 링크**로 전환 측정 (부트캠프 규정: GMV·CVR 직접개선 주장 금지, 선행지표로 검증)
- **저장(찜) 기능 제거** — 낮은 의도의 부가 기능이라 MVP 스코프 아웃 (필요 시 v2)
- 리뷰 전면검색 없음(크롤링 리스크) → 소규모 실험만
- 카테고리 1개 · Loop1 카탈로그 50~100(→ 데이터 보고 확장)

## 검증할 가설 (상위 3)
- **H1(기술)**: 색 바탕/프린팅 분리 등 속성 추출이 신뢰할 정확도로 된다 → Loop1
- **H2(가치)**: 자연어 조합 쿼리로 탐색시간이 극적으로 준다(4시간+실패 → 수분) — 측정은 **과제 기반**(고정 과제로 우리 vs 무신사 비교, PRD §3)
- **H3(수요)**: 타겟 사용자가 이 방식으로 실제 원하는 걸 발견하고 **구매하러 이동한다**

## 미해결
- H1 정확도 임계 수치(Loop1 결과 보고 확정)
- 카탈로그 선정 기준 — 카탈로그 담당, Loop1 초반. **종목 특화가 아니라 "바탕색×프린팅색이 뚜렷이 갈리는 프린팅 티" 위주**(무신사 프린팅 반팔티 일반에서 선별). 조합 검색의 가치가 드러나야 하므로 단색·무지·전면 프린팅만 있는 상품은 후순위. **단 후순위 = 제외가 아니다** — 이 상품들은 같은 50~100개 안에 **대조군 표본**으로 반드시 포함한다(비율은 카탈로그 담당이 Loop1 초반에 정함). 조합 검색이 잘 되는 상품만 담으면 정확도·성공률이 큐레이션 편향으로 부풀려진다(PRD §10 위험)
- 비전LLM 추출 단가 vs 카탈로그 규모(비용 상한) — Loop2 확장 전 점검
