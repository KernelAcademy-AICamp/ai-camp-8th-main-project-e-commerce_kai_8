# 프로젝트 인덱스 — 프린팅 반팔 티셔츠 LLM 검색

> 제품 방법론 파이프라인 산출물 인덱스 · 최초작성 2026-07-21

## 한 줄 정의

사용자가 **말로 표현한 시각·감각 속성**("노란 프린팅 있는 흰 티", "산들산들한 느낌")으로 프린팅 반팔 티셔츠를 찾아주는 LLM 검색 서비스.

## 팀·제약

- 인원 4명 — **캐파는 두 예산으로 나눠 본다**(→ [data-feasibility §0](foundation/data-feasibility.md)): **코드 1명**(+AI 코딩하는 비개발 인원) / **사람(검증) 3명**. "1인 프로젝트"가 아니라 **자동화 1인 + 검증 3인** 구조이고, D6 파이프라인이 그 위에 서 있다.
- 기간 6주, 주 단위 스프린트
- 도구: Claude Code, OpenAI API, 무신사(데이터 소스, D14), **GA4**(계측 표준 — D11·[metrics.md](living/metrics.md)), (선택) Supabase/Vercel/Notion
