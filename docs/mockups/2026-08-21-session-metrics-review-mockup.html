세션 상세 진입률 = 상세가 1개 이상인 세션 / 노출이 1개 이상인 세션
세션 찜 발생률 = 찜 의도가 1개 이상인 세션 / 상세가 1개 이상인 세션
세션 판매처 클릭률 = 판매처 클릭이 1개 이상인 세션 / 상세가 1개 이상인 세션

이 그림은 세션의 상태를 세는 요약이다. 상품별 “노출된 바로 그 상품을 눌렀는가”는 별도의 귀속 분석이며 같은 카드에 섞지 않는다.

4. Claude 답변 판정

적절

표로 충분한 지표는 표로 두고, 원본 기록을 증거 표로 유지한다.

적절

평균만 쓰지 않고 중앙값과 분포를 함께 본다.

적절

찜과 판매처 이동을 직선 단계로 연결하지 않고 상세 뒤 분기로 표현한다.

보완

중앙값만으로는 0이 많은 찜·이동을 숨긴다. 행동 발생 세션 비율이 같이 필요하다.

수정

“기기×날짜 상세 수”는 측정 계획의 “사람×롤링 7일 유효 탐색 일수”와 같지 않다.

수정

현재 노출 횟수는 되돌아보기 횟수가 아니다. 카드 마운트당 첫 50% 노출만 센다.
