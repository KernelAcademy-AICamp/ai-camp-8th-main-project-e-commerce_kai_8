세션 퍼널 — 분기 흐름도 + 필터

실제 프로덕션 데이터 (2026-08-25 11:20 KST). 찜과 판매처 이동은 서로 다른 행동인데 한 세션이 둘 다 할 수 있다. 일렬 퍼널의 마지막 칸에 둘을 넣으면 합이 맞지 않는다.

세션 퍼널 Session flow

갈래를 겹치지 않게 나눈다. 「둘 다」를 독립된 갈래로 두면 모든 세션이 정확히 한 곳에만 속해서 합이 맞는다. 띠 두께가 세션 수다. 이탈도 갈래로 그려서 어디서 얼마나 빠지는지 같이 보인다.

Mixpanel Flows와 Amplitude Pathfinder의 방식. Pathfinder처럼 위에 단계별 숫자를, 아래에 흐름도를 둔다.

이 방식을 고른 이유
겹침을 그림 안에서 해결한다. 각주나 설명으로 밀어내지 않는다. 이탈이 어느 구간에서 나는지 같이 보이고, 필터를 걸면 갈래가 둘로 줄어 더 단순해진다.
감수하는 것
