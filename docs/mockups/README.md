# 목업

구현 전에 **모양만 먼저 보기 위한** 파일들이다. 브라우저로 열면 바로 보인다 — 빌드도 서버도 필요 없다.

**여기 있는 숫자는 전부 가짜다.** 실제 데이터가 아니라 배치·형태를 정하기 위한 것이다.

## 여는 법

파일을 더블클릭하거나, 에디터에서 우클릭 → 브라우저로 열기. 외부 라이브러리를 쓰지 않아 인터넷 없이도 열린다.

## 이 폴더의 파일은 구현이 아니다

목업이 확정되면 실제 코드로 옮기고, 목업은 **그 시점의 결정 기록으로 남긴다.** 나중에 화면이 바뀌어도 목업은 고치지 않는다 — 고치기 시작하면 "언제 무엇을 정했는지"를 잃는다.
