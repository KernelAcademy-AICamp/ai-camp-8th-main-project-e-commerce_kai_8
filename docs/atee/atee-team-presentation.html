07 / Signals
Implicit signals

말하지 않아도,
반복은 말한다.

모든 행동을 구매로 오해하지 않는다. 강도와 한계를 분리해 학습한다.

01반복 탐색 경향weak
02이 스타일로 계속 탐색explicit direction
03찜strong preference
04판매처 이동intent proxy
판매처 이동 ≠ 구매

외부 결제를 알 수 없으므로 가장 강한 ‘구매 의도 대리 신호’로만 사용한다.

노출 편향을 함께 기록

카드 크기 · 화면 위치 · 열 수를 로그에 남겨 시각적 강조를 취향으로 오학습하지 않는다.

The decisive test

UI의 신기함과

Control

같은 모자이크 UI + 공통 다양성 + 세션 분기

장기 행동 프로필 없이도 인터랙션 자체가 만드는 가치를 측정한다.

Treatment

Control + 장기 반복 행동 기반 자동 개인화

찜·판매처 이동·여러 세션 경향을 더해 개인화의 증분 가치를 본다.
