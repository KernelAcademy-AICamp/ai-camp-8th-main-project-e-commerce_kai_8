# aTee product discovery

> 상태: Discovery · 서비스명 `aTee`(확정) · 최종 수정: 2026-08-13

aTee는 기존 `search-by-llm`과 별도의 제품 가설이다. 사용자가 검색어를 만들지 않고 티셔츠 이미지를 계속 훑는 기존 습관에서 출발해, 대중의 베스트 목록 대신 사용할수록 개인 취향에 맞게 변하는 무한 탐색 경험을 검증한다.

## 핵심 문서

1. [팀 발표 자료](atee-team-presentation.html) — 핵심 가설, 제품 경험, 개인화 구조와 검증 계획을 담은 12장 HTML 슬라이드
2. [기회·타깃·JTBD](foundation/problem-target-jtbd.md) — 인터뷰 근거, 행동형 페르소나, 반증 조건
3. [경쟁·대안 분석](foundation/competition.md) — 베스트 목록, 개인화 피드, 비주얼·대화형 쇼핑과의 차이
4. [Living PRD](living/prd.md) — 합의된 제품 경험, MVP 범위, 지표와 검증 게이트
5. [결정 기록](living/decision-log.md) — 질문 과정에서 바뀌거나 확정된 결정

[2026-08-11 프로토타입 감사](foundation/prototype-evidence.md)는 컨셉의 출발점을 확인할 때만 읽는다. 어제의 2차원 궤도형 화면은 현재 제품 요구사항이 아니다.

## 현재 제품 정의

> aTee는 사용자의 장기 취향과 이번 세션의 탐색 경향을 학습하면서, 관련성과 새로움의 구성을 자동으로 조절하는 티셔츠 무한 탐색 PWA다.

- **Evidence:** 탐색적 인터뷰 5~10명 중 약 70%가 검색 시작을 막막해하거나 베스트 목록을 습관적으로 훑는 행동을 설명했다. 원본 기록과 정확한 분모는 남아 있지 않다.
- **Evidence:** 이들은 현재 행동에 뚜렷한 불만이 없으며 장바구니를 호감 상품 보관함으로 사용한다.
- **Decision:** aTee는 고통을 제거하는 검색 도구가 아니라, 대중 순위를 개인화된 발견으로 바꾸는 가치 창출형 제품이다.
- **Decision:** 완료 상태나 2~5개 후보 압축 없이 무한 탐색을 유지한다.
- **Assumption:** 사용자는 화면의 상품 구성이 반복 선택과 닮아가는 것을 보고 ‘나의 취향’을 체감하며 다시 방문한다.
- **Open question:** 개인화 피드가 같은 UI의 비개인화 피드보다 7일 내 재방문을 실제로 높이는가?

## 문서 원칙

- 사용자 발화, 제품 결정, 아직 검증하지 않은 가설을 구분한다.
- `판매처 이동`은 구매 의도 대리 지표이지 실제 결제나 매출이 아니다.
- 체류시간은 혼란 때문에 늘 수 있으므로 재방문율과 가드레일 없이 성공으로 판단하지 않는다.
- 인구통계는 타깃을 꾸미는 정보가 아니라 착용 가능 조건과 분석 세그먼트로만 사용한다.
- 구현 설계와 작업 계획은 PRD가 정리된 뒤 별도 문서로 만든다.
