# aTee Living PRD

> 버전: 0.5 · 상태: 제품 정의 합의 / 가치 검증 전 / engineering-ready 아님 · 최종 수정: 2026-08-14
> 제품 책임자: 프로젝트 오너 · 서비스명: aTee(확정) · [결정 기록](decision-log.md)

## 1. Executive summary

aTee는 검색 목적 없이 티셔츠 이미지를 습관적으로 훑는 사용자를 위한 개인화 무한 탐색 PWA다. 사용자는 2열 masonry 무한 피드에서 이미지와 가격에 집중하고, 탐색 중 반복한 선택·찜·판매처 이동을 바탕으로 점점 자신에게 맞는 상품과 취향 경계 밖의 상품을 함께 본다.

aTee는 현재 쇼핑의 뚜렷한 고통을 해결한다고 주장하지 않는다. 베스트 목록과 장바구니에 이미 만족하는 사용자가 대중 순위 대신 ‘나의 취향으로 변하는 피드’를 더 오래 탐색하고 다시 찾는지 검증하는 가치 창출형 제품 가설이다.

초기 성공은 매출이 아니라 **가입 후 7일 이내 자발적 재방문**으로 판단한다. 같은 UI의 비개인화 피드와 개인화 피드를 비교해 인터페이스의 신기함과 개인화 가치를 분리한다.

## 2. 문제·기회와 근거

### 관찰된 행동

- 기존 LLM 패션 검색 프로젝트의 탐색적 인터뷰 5~10명 중 약 70%가 검색 시작을 막막해하거나, 무신사 베스트 목록을 별 생각 없이 반복 스크롤하는 평소 행동을 설명했다.
- 이들은 옷을 사야 한다는 느슨한 필요가 생기면 이미지를 훑고, 마음에 든 상품을 장바구니에 담아 나중에 다시 본 뒤 일부를 구매한다.
- 이 행동에 뚜렷한 불만이나 고통을 표현하지 않았다.
- 정확한 분모, 질문지, 개별 발화 기록은 남아 있지 않아 탐색적 질적 단서로만 사용한다. 자세한 해석은 [기회·타깃·JTBD](../foundation/problem-target-jtbd.md)를 따른다.

### 제품 기회

베스트 목록은 불특정 다수의 행동으로 정해진 목록이다. aTee는 사용자의 반복 탐색을 학습해 이미 좋아할 가능성이 높은 상품뿐 아니라 일부만 일치하는 디자인, 반대 스타일, 신상품을 계속 섞어 보여준다. 사용자는 취향을 직접 설정하지 않고도 화면 전체의 구성이 과거 선택과 닮아가는 것을 보고 개인화 가치를 느낀다.

### 현재 근거의 한계

- 사용자가 현재 방식에 만족하므로 ‘불편해서 전환한다’는 논리를 사용할 수 없다.
- 장기 재방문과 개인화 체감은 아직 측정하지 않았다.
- 2026-08-11 2차원 궤도형 프로토타입은 컨셉 출발점일 뿐 사용자 가치 근거가 아니다. [프로토타입 감사](../foundation/prototype-evidence.md)

## 3. 타깃과 JTBD

### 1차 타깃

> 무신사에서 매주 베스트 목록을 습관적으로 훑고, 마음에 드는 상품을 장바구니에 담아두었다가 나중에 구매하는 사람.

모집 기준은 최근 4주 동안 주 1회 이상 모바일 무신사 베스트 목록을 탐색했고, 장바구니를 호감 상품 보관함으로 사용한 경험이 있는 사람이다. 연령과 직업은 타깃 조건이 아니다.

### JTBD

> 살 옷을 구체적으로 정하지 않았지만 티셔츠를 구경하고 싶을 때, 검색어를 만들거나 대중의 베스트 순위를 그대로 따라가지 않고, 내가 반복해서 선택한 취향과 그 경계 밖의 제안을 계속 탐색해 새롭게 마음에 드는 상품을 발견하고 싶다.

### 비타깃

- 정확한 상품·브랜드·조건을 알고 빠르게 찾으려는 목적형 쇼퍼
- aTee 안에서 결제·배송·반품까지 완료하려는 사용자
- 티셔츠 외 의류를 탐색하려는 사용자는 첫 MVP 대상이 아니다.

## 4. 전략적 맥락과 포지셔닝

무신사의 발견형 큐레이션, Daydream의 대화형 쇼핑, Google·Amazon의 비주얼 유사 상품, Pinterest·Cosmos의 시각 영감 탐색은 인접한 문제를 이미 해결한다. aTee의 차이는 AI 추천 자체나 무한 피드가 아니라 다음 조합에 있다. 자세한 내용은 [경쟁·대안 분석](../foundation/competition.md)을 따른다.

- 검색어 없이 이미지 탐색 자체가 학습 입력이 된다.
- 장기 취향과 이번 세션의 방향을 별도 속도로 반영한다.
- 유사도에만 수렴하지 않고 익숙함·부분 일치·반대 스타일을 의도적으로 섞는다.
- 실제 티셔츠 이미지와 가격에 집중하고 거래는 판매처에 맡긴다.

지금 검증하는 이유는 기존 LLM 검색 인터뷰에서 검색 대신 습관적으로 이미지를 훑는 행동이 발견됐고, 사용자 제공 정보상 약 22만 개의 무신사 티셔츠 데이터가 있어 이 가설을 한 카테고리에서 시험할 조건이 마련됐기 때문이다. 데이터의 실제 사용 가능성은 Gate 0에서 별도로 확인한다.

초기 사업 목적은 가치 검증이다. 광고, 스폰서 노출, 제휴 수익 최적화와 유료 개인화는 범위 밖이다.

## 5. 원하는 결과와 지표

### 사용자 결과

- 검색어나 취향 설정 없이 바로 티셔츠를 훑는다.
- 사용할수록 화면 구성이 ‘남의 베스트’가 아니라 ‘나의 취향’이라고 느낀다.
- 익숙한 취향과 예상 밖의 디자인을 무한히 오가며 탐색한다.
- 마음에 든 상품을 찜하거나 상세·판매처로 이동한 뒤 기존 위치로 돌아온다.
- 다음 쇼핑 순간에 aTee를 다시 연다.

### Primary metric

**회원 D7 자발적 재방문율**

- 단위: 신규 회원 한 명
- 분모: 가입 온보딩을 완료하고 배정된 실험 피드를 한 번 이상 탐색한 신규 회원
- 분자: 최초 실험 세션 다음 날부터 7일 이내, 푸시 알림 없이 aTee를 다시 열어 유효 탐색을 시작한 회원
- 기준선: 동일 UI의 비개인화 대조군에서 측정
- 목표: 기준선과 표본을 확보하기 전까지 TBD
- 미달 시: 개인화 모델 확대와 푸시 도입을 보류하고 신호·추천 포트폴리오·가치 제안을 재검토

첫 비교 실험에서는 푸시를 사용하지 않는다. 푸시는 유기적 재방문 가치가 확인된 뒤 별도 효과로 측정한다.

### Supporting metrics

| 지표 | 단위와 의미 |
|---|---|
| 유효 탐색 시간 | 백그라운드·비활성 시간을 제외한 세션당 중앙값. 긴 시간이 혼란 때문인지 가드레일과 함께 본다. |
| 7일 내 탐색 세션 수 | 신규 회원 한 명이 D1~D7에 시작한 유효 탐색 세션 수 |
| 개인화 체감 | 테스트 후 “이 피드는 내 취향을 반영했다”는 응답. 문항과 척도는 테스트 전에 고정 |
| 스타일 방향 전환율 | 상세 화면을 연 사용자 중 하단 닮은 상품 탐색으로 이어간(탐색 카드 탭) 비율. 전용 버튼은 O-30으로 제거되어 하단 탐색 기준으로 잰다 |
| 찜률 | 상품 노출 또는 상세 화면 기준 찜 비율. 구매로 간주하지 않음 |
| 판매처 이동률 | 상세 화면 기준 외부 판매처 이동 비율. 구매 의도 대리 지표이며 결제가 아님 |
| 비회원→회원 전환율 | 가입 제안을 본 비회원 중 온보딩을 완료한 비율 |

세션 지표의 세션 경계는 **마지막 활동 후 비활성 30분**으로 정의한다(O-29). 클라이언트가 판정하며, 계측 결과에 따라 조정할 수 있다.

### Guardrails

- 동일 상품·동일 스타일 반복 노출률
- 추천 포트폴리오의 다양성과 반대 제안 노이즈율
- 성별·키·사이즈 조건에 맞지 않는 상품 노출률
- 잘못된 탭·길게 누르기와 핵심 동작 도움 요청률
- 가입 온보딩 이탈률
- 외부 판매처 복귀 시 탐색 상태 복원 실패율
- 이미지 지연과 레이아웃 이동으로 인한 탐색 중단률

정확한 이벤트 정의, 비활성 시간, 목표값과 최소 효과는 실험 계획에서 사전 확정한다.

## 6. 제품 경험

### 온보딩 — 첫 방문 (2026-08-24부터, O-41)

첫 홈에 닿기 전에 세 단계를 거친다. 진행 표시는 `1 / 3`·`2 / 3`·`3 / 3`이다.

1. **성별 선택** — 남/여 중 하나를 고른다. 고르기 전에는 아무것도 보여주지 않고 추천 요청도 시작하지 않는다(O-39).
2. **좋아하는 옷 선택** — 고른 성별과 같은 라벨의 실제 티셔츠 10~12개를 2열 카드로 보여주고 **최소 3개**를 고르게 한다. 스타일 용어 체크박스를 거치는 다단계 구조를 쓰지 않는다. 후보는 색·그래픽·핏·무드가 서로 구분되게 구성하며 대중 인기 순위만으로 정하지 않는다.
3. **회원가입** — 화면의 주인공은 `가입`이 아니라 `취향 찾기를 계속하는 가치`다. 직전에 고른 옷을 다시 보여주고, 그 선택이 첫 추천의 시작점이며 이후 탐색으로 추천이 달라진다는 두 가지 효용만 설명한다. 구글 로그인 버튼 하나만 둔다.

**선택은 로그인 전까지 기기에만 둔다.** 계정이 생긴 뒤 계정에 붙인다 — 비로그인 서버 기록을 만들지 않는다(O-41).

첫 홈에서는 전체 화면을 막는 튜토리얼을 쓰지 않는다. 개인화 결과를 즉시 보여주고 스크롤을 막지 않는 짧은 확인 메시지를 한 번만 띄운다. 초기 추천 준비에 성공했을 때만 `개인화된 추천이 준비됐다`고 표현한다.

4. ~~가입 전 임시 탐색 행동을 계정 프로필로 승계한다.~~ → **2026-08-18 변경 (O-35): 취향 프로필은 승계하지 않는다.** 로그인·로그아웃으로 신원이 바뀌면 이전 신원의 취향을 **지운다.** 한 기기를 여럿이 쓸 때 앞사람의 취향이 새는 것을 막는 쪽을 택했다. 승계는 프로필이 계정 소유가 되는 시점에 다시 판단한다.
   - **2026-08-19 예외 (O-36): 찜은 옮긴다.** 취향 프로필은 우리가 계산한 결과지만 찜은 사용자가 손으로 누른 것이라 성격이 다르다. 옮기는 것은 **익명 → 사용자 전환뿐**이다.
   - **2026-08-24 예외 (O-41): 온보딩에서 고른 옷도 옮긴다.** 같은 원칙이다 — 우리가 계산한 것이 아니라 **사용자가 손으로 누른 것**이다. 이것은 `계산된 취향 승계`가 아니라 **사용자의 명시적 선택 승계**이며, 계정의 초기 추천 근거로만 쓴다. 계산된 장기 취향과 같은 데이터로 취급하지 않는다.

5. **로그인이 필수다 (2026-08-24, O-41).** 첫 홈은 가입을 마쳐야 열린다. 인증을 취소하거나 실패하면 회원가입 화면으로 돌아오고 앞서 고른 성별·옷 선택은 사라지지 않는다.

### 찜 (2026-08-19부터)

- **찜은 계정 데이터다.** 로그인해야 담을 수 있고, 기기를 넘어 따라온다. 담는 것은 상품 번호와 담은 시각뿐이라 목록을 열 때 현재 가격이 보인다.
- 로그인하지 않은 사람에게는 찜과 찜 목록이 **로그인 유도로 바뀐다.** 피드·검색·상세는 로그인 없이 그대로 쓸 수 있다.
- 이 변경으로 **비회원에게서는 찜 신호가 더 이상 생기지 않는다.** 개인화가 쓰는 세 신호(노출·탭·찜) 중 가장 강한 것이므로, 비회원 피드 품질에 주는 영향을 관찰한다.
5. 초기 취향 근거가 부족하면 자격 조건을 통과한 상품 중 색상·그래픽·핏·가격대를 다양하게 보여주며 빠르게 학습한다. 인기 순위를 중심 기준으로 삼지 않는다.

### 회원 개인화 루프

> 검증 순서(O-24): 가입 기능 구현 전, 익명 기기 ID 기반 프로토타입으로 이 루프를 먼저 검증한다. 이 프로토타입은 Gate 1(회원 D7 실험)이 아니며, Gate 1의 실험 단위는 여전히 회원이다. ~~계정 도입 시 기기 프로필을 승계한다.~~ → **2026-08-18 변경 (O-35): 승계하지 않고, 신원이 바뀌면 지운다.**

1. 첫 화면은 장기 취향을 기반으로 관련 상품과 의도적 탐색 상품을 섞는다.
2. 사용자가 특정 스타일을 선택하면 현재 세션 방향을 빠르게 그쪽으로 이동시킨다.
3. 현재 세션이 장기 취향과 달라도 장기 취향 상품을 소량 유지한다.
4. 단발 클릭보다 여러 세션에서 반복된 탐색 경향을 신뢰한다.
5. 찜과 판매처 이동은 강한 긍정 신호로 반영하되 실제 구매로 기록하지 않는다.
6. 상품 노출은 끝나지 않으며 정해진 후보 수나 완료 상태를 만들지 않는다.

### 상세과 외부 이동

- 피드 카드에는 상품 이미지와 가격만 노출하며, 가격은 이미지 위 배지로 표시한다.
- 탭은 카드가 확대되는 전환으로 상세 화면을 연다.
- 상세 화면은 상품 이미지 슬라이드, 상품 식별과 판매처 이동에 필요한 상세, 찜, 그리고 화면 아래로 이어지는 닮은 상품 탐색(진입 즉시 로딩)을 제공한다. 전용 `이 스타일로 계속 탐색` 버튼은 O-30으로 제거했다.
- 길게 누르기 단축 동작은 보류한다(O-30 — 단축 대상이던 전용 버튼이 없어짐. 세션 방향 전환 UI 재도입 시 재검토).
- 최초 온보딩에서 탭 상세를 직접 안내한다(길게 누르기 안내는 보류 — O-30).
- 상세 화면에서 돌아오거나 판매처에서 돌아오면 이전 스크롤 위치와 피드 상태를 유지한다.

### 실패와 복구

- 개인화 계산을 사용할 수 없으면 자격 조건을 통과한 다양성 피드로 복구하고 개인화된 결과인 것처럼 표시하지 않는다.
- 성별·사이즈 자격을 확인할 상품이 부족하면 맞지 않는 상품을 섞지 않고, 사용자에게 조건 수정 또는 데이터 부족을 알린다.
- 이미지·가격·판매처 링크가 유효하지 않은 상품은 피드에서 제외한다.
- 이미지 로딩 전 영역을 예약해 카드가 움직이지 않게 하고, 실패한 이미지는 재시도 또는 명확한 대체 상태를 제공한다.
- 판매처 링크가 열리지 않으면 탐색 상태를 유지한 채 재시도할 수 있다.
- 길게 누르기를 지원하지 않거나 충돌하는 환경에서는 스타일 탐색 버튼을 제공한다.
- 연결이 끊기면 이미 받은 피드와 찜을 가능한 범위에서 유지하고, 재연결 뒤 중복 없이 이어간다. 정확한 오프라인 범위는 기술 설계에서 확정한다.

## 7. 개인화 원칙과 평가

### 추천 포트폴리오

모든 개인화 피드는 다음 유형을 포함한다. 고정 비율은 아직 결정하지 않고 행동에 따라 자동 조절한다.

1. **장기 취향:** 구매가 아니라 여러 세션의 반복 탐색·찜·판매처 이동과 유사한 상품
2. **현재 관심:** 이번 세션에서 최근 선택한 방향과 관련된 상품
3. **부분 일치:** 색·그래픽·핏·가격 등 일부 축만 맞는 상품
4. **반대 제안:** 현재 프로필과 의도적으로 다른 스타일
5. **시간적 새로움:** 위 유형 중 새로 출시·입고된 상품

`신상품`은 독립된 취향 유형이 아니라 각 유형에 적용되는 시간 축이다. 반대 제안은 제거하지 않되 노이즈가 되지 않도록 반응을 측정한다.

### 신호 강도

기본 순서는 다음과 같다.

`반복 탐색 경향 < 이 스타일로 계속 탐색 < 찜 < 판매처 이동`

- `이 스타일로 계속 탐색` 명시 신호는 전용 버튼 제거(O-30)로 보류 상태다 — 서열 정의는 유지하되 현재 UI에서는 발생하지 않는다.

- 오래 보기와 단발 클릭은 의미가 모호하므로 약한 보조 신호로만 사용한다.
- 빠르게 지나쳤다는 이유만으로 싫어한다고 단정하지 않는다.
- 추천으로 많이 노출했기 때문에 다시 많이 본 자기강화 효과를 막기 위해 노출 대비 행동을 계산한다.
- 카드 크기와 화면 위치를 모든 노출 이벤트에 기록해 시각적 강조 효과를 취향으로 오학습하지 않는다.

### 장기 취향과 세션 취향

- 장기 취향은 여러 세션의 반복 행동으로 천천히 변한다.
- 세션 취향은 이번 세션의 행동(탭·찜·상세 하단 탐색)으로 빠르게 변한다. (전용 스타일 탐색 버튼과 그에 따른 세션 부스트는 보류 — O-30)
- 한 세션의 이례적 탐색이 장기 프로필을 즉시 덮어쓰지 않는다.
- 명시적 `관심 없음/이 스타일 줄이기`는 후속 단계로 둔다.

### 평가 요구

- 같은 UI에서 비개인화 정책과 개인화 정책을 비교한다.
- 오프라인 평가는 성별·사이즈·가격대·스타일 속성으로 층화한 티셔츠 표본을 사용하며, 표본 수와 사람 판정 프로토콜은 Gate 0 전에 고정한다.
- 추천 노출마다 포트폴리오 유형, 순위, 카드 크기, 열 수, 신선도와 사용 가능한 자격 데이터를 기록한다.
- 유사성뿐 아니라 반복률, 다양성, 신상품 커버리지, 유형별 찜·판매처 이동을 함께 본다.
- 성별·사이즈 자격이 확인되지 않은 상품은 회원 개인화 피드에서 제외한다.
- 추천 변경 전 동일 사용자·상품 시나리오 평가셋으로 회귀를 확인한다. 평가셋과 최소 기준은 데이터 감사 후 확정한다.
- 오프라인 관련성·다양성 평가는 온라인 D7 재방문과 분리해 보고하며, 어느 하나를 다른 하나의 성공으로 대체하지 않는다.
- 추천 응답 시간과 계산 비용의 단위·예산은 아키텍처 기준선 측정 후 기술 설계에서 확정하고 Gate 1 전에 잠근다.

## 8. MVP 범위와 요구사항

### P0 — 개인화 가치 검증

- 모바일 우선 PWA와 설치하지 않은 모바일 브라우저 모두에서 핵심 탐색 동작
- 무신사 티셔츠 카탈로그만 사용
- 비회원의 비개인화·다양성 피드와 현재 세션 스타일 탐색
- 2열 고정 masonry(카드 세로 길이 가변, 이미지 위 가격 배지) 무한 스크롤 피드
- 탭 상세 화면(카드 확대 전환, 이미지 슬라이드), 찜, 상세 하단 닮은 상품 탐색(즉시 로딩), 판매처 이동
- 길게 누르기 단축 동작(보류 — O-30)
- 핵심 제스처를 체험하는 최초 온보딩
- 점진적 가입 제안, 가입 전 임시 탐색 이력 승계
- 연령대·성별·키·사이즈 가입 정보와 회원 개인화
- 장기 취향·세션 취향·부분 일치·반대 제안·신상품을 포함한 추천 포트폴리오
- 찜 보관함과 찜의 개인화 반영
- 상세 화면·외부 판매처 방문 뒤 탐색 상태 복원
- 동일 UI의 비개인화 대조군과 개인화 실험에 필요한 계측
- 개인 데이터 수집 목적 고지, 동의, 계정·탐색 이력 삭제 수단

### P1 — 가치 확인 후 유지 강화

- 충분한 개인화 이력이 있는 회원 대상의 관련 신상품·취향 확장 PWA 푸시
- 명시적 알림 동의와 빈도 조절
- PWA 설치 안내 최적화
- 찜 변화·가격 변화 등 재방문 알림 후보 검증

### P2 — 후속 개인화 통제와 확장

- `관심 없음`, `이 스타일 줄이기`, 취향 초기화·수정
- 티셔츠 외 카테고리 확장
- 판매처 전환 데이터 제휴와 실제 구매 신호 연동 검토
- 수익 모델 검토

### Non-goals

- 자연어·키워드 검색을 aTee의 주 경험으로 제공 (O-25: 보조 진입점 검색은 예외로 허용 — 결과는 피드 형태로 이어져 탐색으로 복귀. 별도 스펙)
- 자체 결제, 주문, 배송, 반품
- 판매처 이동을 실제 구매·매출로 집계
- 광고·스폰서 상품과 수익 최적화
- 소셜 피드, 팔로우, 공개 컬렉션
- 생성형 이미지나 존재하지 않는 상품 노출

## 9. 데이터·플랫폼 제약

- **사용자 제공 정보:** 현재 DB에 무신사 티셔츠 약 22만 개가 적재돼 있다.
- **미검증:** 이 작업에서는 라이브 DB 총량과 이미지·가격·성별·사이즈·재고·링크의 유효 커버리지를 확인하지 못했다. MVP 전 데이터 감사를 통과해야 한다.
- 상품은 유효한 이미지, 현재 가격, 판매처 링크와 회원 자격 조건 판정에 필요한 데이터를 가져야 노출할 수 있다.
- 가격·품절·판매처 링크의 갱신 시점과 실패율을 추천 품질과 별도로 측정한다.
- 개인화 기반 데이터: 전 상품 이미지(썸네일+갤러리 약 93만 장)의 SigLIP2 임베딩을 사용한다(O-26·O-27). 저장은 Supabase Pro(유료) 전제(O-28)이며, 검증 종료 후 벡터 테이블 삭제로 무료 복귀 가능하다.
- PWA는 브라우저에서 설치 없이 동작하며, 설치 후에도 같은 계정·탐색 상태를 사용한다.
- 길게 누르기가 브라우저·OS 동작과 충돌할 경우 동일 기능의 명시적 컨트롤을 우선한다.
- 푸시는 지원 환경과 명시적 동의가 있는 회원에게만 제공하고 핵심 탐색의 필수 조건으로 두지 않는다.

## 11. 검증과 출시 단계

### Gate 0 — 데이터·상호작용 준비

- 약 22만 개 카탈로그의 실제 총량과 필수 필드 커버리지를 확인한다.
- 2열 masonry 피드에서 무한 스크롤이 끊김 없이 이어지고, 상세 화면·외부 판매처 복귀 후 스크롤 위치가 유지된다.
- 탭 상세 화면, 이미지 슬라이드, 스타일 계속 탐색, 찜과 판매처 이동을 설명 없이 수행할 수 있는지 1차 타깃 5~8명에게 확인한다.
- 통과 수치와 허용 오류는 테스트 시작 전에 확정한다.

미통과 시 추천 모델 개발을 확대하지 않고 데이터 또는 핵심 조작부터 수정한다.

### Gate 1 — 개인화 가치 대조 실험

- 대상: 1차 타깃 조건을 만족하고 가입 온보딩을 완료한 폐쇄 베타 회원
- 공통: 동일한 모자이크 UI, 상품 범위, 상세과 명시적 스타일 탐색
- 대조군: 공통 다양성 정책과 현재 세션의 명시적 스타일 분기만 사용
- 실험군: 대조군 경험에 장기 반복 행동·찜·판매처 이동 기반 자동 개인화를 추가
- Primary: D7 자발적 재방문율
- Supporting: 유효 탐색 시간, 개인화 체감, 찜, 스타일 방향 전환, 판매처 이동
- Guardrail: 반복, 다양성, 착용 불가 노출, 조작 실패, 가입 이탈
- 최소 표본과 최소 개선 폭은 노출 전에 확정하며, 결과를 본 뒤 목표를 바꾸지 않는다.

개인화가 D7 재방문과 유효 탐색을 개선하지 못하면 개인화 확대와 푸시를 중단하고 가설을 재검토한다. 판매처 이동이 낮더라도 재방문 가치가 명확하면 발견 제품 가설은 별도로 유지할 수 있다.

### Gate 2 — 유지와 외부 대안 비교

- Gate 1 통과 후 개인화 푸시의 증분 재방문 효과를 별도 실험한다.
- 이후 aTee 전체 경험을 무신사 베스트 탐색과 비교해 실제 대체·보완 가치를 확인한다.
- 반복 사용 뒤에도 개인화 체감과 새로움이 유지되는지 종단 관찰한다.
