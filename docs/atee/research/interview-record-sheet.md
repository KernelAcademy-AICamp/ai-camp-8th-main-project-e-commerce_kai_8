> 버전 **v1** (파일럿 전) · 작성 2026-08-18
> 참여자 1명당 1장. **인쇄해서 손으로 채운다.**

화면 녹화가 없으므로 이 종이가 유일한 행동 기록이다. 녹음은 말만 남는다.

## 2. 조작 판정

**판정 기준**

| 표시 | 뜻 |
|---|---|
| **○** | 헤매지 않고 **첫 시도**에 성공 |
| **△** | **눈에 띄게 멈칫**했거나, 엉뚱한 곳을 한 번 이상 누른 뒤 성공 |
| **✕** | 끝내 못 함 (2분 이상 완전히 멈춰 진행자가 개입한 경우 포함) |
| **—** | 판정 불가 (참여자가 시도하지 않음 / 기능이 제외됨) |

초를 세지 않는다. **"막힘없이 갔다"고 보이면 ○, "어? 하고 멈칫"하면 △** 로 매긴다. 애매하면 △로 내린다.

**구간 표시:** 자유 탐색 중이면 `자`, 과업 구간이면 `과`(A안만).

> ⚠️ **`자`와 `과`는 다른 지표다.** Gate 0("설명 없이 수행")의 판정치는 **`자` 구간의 ○** 뿐이다. `과` 구간 성공은 "목적을 알려주면 찾아낸다"까지만 뜻하므로 통과 판정에 넣지 않는다. B안은 `과` 구간이 없어 전부 `자`다.

## 세션 직후 확인 (5분)

- [ ] 녹음 파일이 실제로 저장됐는지 재생해서 확인
- [ ] 조작 표에 빈칸이 없는지 (판정 불가는 `—`로 채운다)
- [ ] 멈춤 로그의 시각이 녹음 시각과 맞는지
- [ ] 진행자와 기록자가 **각자 매긴 판정이 다른 항목**이 있는지 대조 → 다르면 그 자리에서 이유를 적어둔다

마지막 항목은 채점 기준이 모호하다는 신호다. 파일럿에서 불일치가 나오면 **채점표 정의를 고친다.**
