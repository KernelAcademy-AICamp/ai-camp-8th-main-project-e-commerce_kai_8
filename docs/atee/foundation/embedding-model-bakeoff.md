# 이미지 임베딩 모델 비교 (bake-off)

> 실행: 2026-08-14 · 상태: **확정 — SigLIP2-Base 선택** · 관련: [카탈로그 감사](catalog-audit.md), 개인화 알고리즘 설계(진행 중)

## 목적

개인화 탐색(유사 이미지)·LLM 자연어 검색(텍스트→이미지)·이미지 유형 분류(zero-shot)를 하나의 임베딩으로 감당할 텍스트-이미지 공동 공간 모델을 실데이터로 비교해 선택한다.

## 후보와 사전 조사

| | Marqo-FashionSigLIP | SigLIP2-Base | jina-clip-v2 |
|---|---|---|---|
| 성격 | 패션 특화 파인튜닝 (GCL) | 범용 다국어 (Google) | 범용 다국어 89개 언어 |
| 파라미터 | 0.2B | 0.4B급 (base-patch16-256) | 0.9B |
| 라이선스 | Apache 2.0 | Apache 2.0 | CC BY-NC (비상업) |
| 한국어 텍스트 | ✗ (영어 전용) | ⭕ 직접 지원 | ⭕ 직접 지원 |

- jina-clip-v2의 비상업 라이선스는 이 프로젝트(포트폴리오용 비상업)에서는 허용 가능으로 판단했다.
- 참고 자료: [marqo-FashionCLIP GitHub](https://github.com/marqo-ai/marqo-FashionCLIP) · [SigLIP 2 소개](https://huggingface.co/blog/siglip2) · [jina-clip-v2](https://huggingface.co/jinaai/jina-clip-v2)

## 방법

- **표본:** `c_feed_page` RPC(시드 777)로 무작위 1,500개 상품 → 썸네일 1,498장 확보 (2장은 404 — 썸네일 URL 노화 재확인).
- **이미지 질의:** farthest-point sampling으로 다양하게 뽑은 8개 상품 각각에 대해 모델별 "닮은 옷 Top-8"을 나란히 비교.
- **텍스트 질의:** 한국어/영어 쌍 8종(무지 흰색, 스트라이프, 빈티지 워싱 그래픽, 캐릭터 프린트, 미니멀 로고, 오버핏 검정, 레터링, 파스텔 여름). 영어 전용인 Marqo는 실운용 구조(LLM이 영어로 정규화)대로 영어 질의만 사용.
- **환경:** Apple M1 16GB (MPS), PyTorch 2.13, 이미지 500px 리사이즈.
- 비교 페이지(compare.html)와 스크립트는 세션 스크래치패드에서 생성 — 본 파이프라인 구현 시 `backend/`에 정식 구현 예정.

## 결과

### 배치 속도 (1,498장, 모델 로드 포함)

| 모델 | 표본 소요 | 93만 장(썸네일+갤러리 전체) 환산 |
|---|---|---|
| Marqo-FashionSigLIP | 96초 | 약 13시간 |
| **SigLIP2-Base** | **71초** | **약 11시간 (하룻밤)** |
| jina-clip-v2 | 1,713초 | **약 12일 — 실행 불가 수준** |

### 텍스트 검색 제목 키워드 대략 채점 (Top-8 중 제목에 기대 키워드 포함 수 — 참고용)

| 질의 | Marqo(영) | SigLIP2(한) | SigLIP2(영) | jina(한) | jina(영) |
|---|---|---|---|---|---|
| 무지 흰색 | 3/8 | 3/8 | 2/8 | 3/8 | 3/8 |
| 스트라이프 | 5/8 | 5/8 | 7/8 | 6/8 | 5/8 |
| 레터링 | 3/8 | **6/8** | 3/8 | 2/8 | 0/8 |
| 오버핏 검정 | 3/8 | 3/8 | 4/8 | 1/8 | 3/8 |

- 제목에 키워드가 없어도 정답일 수 있는 거친 지표다. 최종 판단은 비교 페이지 눈 검증으로 했다.
- jina는 "89개 언어 지원" 명성과 달리 한국어 질의에서 우위가 없었다.

### 눈 검증

제품 책임자가 유사 이미지 검색 8세트와 텍스트 검색 결과를 모델별로 비교 — SigLIP2의 한국어 질의 품질이 실사용에 충분하다고 판단.

## 결정

**`google/siglip2-base-patch16-256` (SigLIP2-Base) 채택. 검색의 한국어 질의는 임베딩 모델이 직접 처리한다.**

근거:

1. **속도** — 전 후보 중 최속(93만 장 하룻밤). jina는 12일로 탈락.
2. **한국어 직접 지원** — 검색 흐름에서 LLM 영어 정규화 없이 한국어 문장을 바로 벡터로 변환 가능. (LLM 정규화 경로는 품질 보강 옵션으로 유지)
3. **라이선스** — Apache 2.0, 상업 전환에도 제약 없음.
4. **품질** — 패션 특화 Marqo 대비 유사 이미지·텍스트 검색에서 밀리지 않았고 한국어 질의에서는 앞섰다(키워드 채점 + 눈 검증).

### 유의점 (구현 시)

- transformers 5.x에서 `get_image_features`/`get_text_features`가 텐서가 아닌 출력 객체를 반환할 수 있다 — `pooler_output` 추출 필요.
- 텍스트 토크나이즈는 `padding="max_length", max_length=64` 필요 (SigLIP 학습 조건).
- 임베딩 차원 768. 이진 양자화 등 압축 적재 전 품질 게이트(원본 대비 상위 결과 겹침률)는 설계대로 수행.
