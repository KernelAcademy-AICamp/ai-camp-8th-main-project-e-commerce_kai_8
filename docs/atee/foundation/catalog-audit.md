# 티셔츠 카탈로그 데이터 감사 (Gate 0 데이터 항목)

> 상태: 측정 완료 / 노출 조건·통과 기준 미확정 (제품 책임자 결정 대기) · 감사일: 2026-08-14
> 대상: Supabase `c_goods` (2026-08-12 수집분) · 계획: [감사 계획](../../plans/2026-08-14-catalog-audit.md)
> 방법: 전수 SQL 집계 + 무작위 표본 600개 라이브 검증 (95% 신뢰수준 ±4%p, p=0.5 최악 가정, 동시 6 이하)

## 요약

- 실제 총량 **226,320행** — 사용자 제공 정보(약 22만)와 일치.
- 피드 노출 최소 조건(썸네일·가격·제목)은 **사실상 전부(226,319개, 100.0%)** 충족. 깨진 행은 단 1건.
- 성별은 99.2%가 보유하고 값도 남성/여성/공용 3종으로 깨끗함.
- **사이즈가 가장 약한 고리** — 값이 표준화돼 있지 않아 정규화 규칙을 적용해도 71.9%만 성별+사이즈 자격 판정 가능.
- 라이브 표본 600개: 이미지·판매처 링크 **전부 유효**(실패 0), 판매중 **98.8% ±0.9%p**, 가격 일치 **93.5% ±2.0%p**(수집 이틀 뒤 기준).
- 남은 결정 3가지(노출 조건, 사이즈 결손 취급, 가격 신선도 기준)는 §5에 선택지로 정리 — 제품 책임자 결정 대기.

## 2. 값 품질

### 성별 — 자격 판정에 바로 사용 가능

| 값 | 행 | 비율 |
|---|---:|---:|
| 남성 | 93,394 | 41.3% |
| 여성 | 89,922 | 39.7% |
| 공용 | 41,093 | 18.2% |
| (없음) | 1,911 | 0.8% |

### 가격 — 이상값 없음

- 0원·음수·1,000원 미만: **0건**. null 1건(위 깨진 행).
- 범위 3,180 ~ 2,470,000원, 중앙값 40,320원. 100만 원 초과는 12건(명품 티셔츠로 보이는 수준의 소수).

### 이미지 경로 — 형식 일관

- 썸네일: 전부 http 절대경로.
- 갤러리: 전부 루트 상대경로(`/images/...`) — CDN 도메인(`image.msscdn.net`)을 붙여야 함(상세 화면 구현에서 이미 확인된 사실과 일치).

### 사이즈 — 가장 약한 고리

`sizes` 값이 표준화돼 있지 않다. 형태가 최소 6종류 섞여 있다:

| 형태 | 예 | 비고 |
|---|---|---|
| 표준 문자 | M, L, XL, FREE | 가장 흔함 |
| 색상^사이즈 | `블랙^M`, `화이트^L` | 옵션 문자열이 그대로 들어옴 |
| 사이즈^색상 | `M^Black` | 순서 반대 버전 |
| 문자_숫자 | `L_100`, `XL_105` | |
| 번호(숫자) | `04(95)`, `05(100)` | |
| 판정 불가 | `NONE`(9,778개 상품), `1`/`2`/`3`, 색상 단독 | 옵션 인덱스·정보 없음 |

- 1차 엄격 규칙(표준 문자 + 한국 치수 80~120)으로는 **64.6%**, 위 형태를 흡수하는 확장 정규화로는 **72.3%** 상품에서 사이즈 판정 가능.
- **성별+사이즈 모두 판정 가능(회원 자격 필터의 전제): 162,735개, 71.9%.**
- 남은 28%는 `NONE`·옵션 인덱스 등 정보 자체가 없어 정규화로 더 올리기 어려움. PRD 원칙상 "자격 미확인 상품은 회원 개인화 피드에서 제외"이므로, 회원 피드의 모수가 약 16.3만 개가 된다는 뜻.

## 3. 라이브 표본 검증 (표본 600개)

수집(2026-08-12) 이틀 뒤인 2026-08-14 기준. 신뢰구간은 95% 수준.

| 항목 | 결과 | 신뢰구간 |
|---|---|---|
| 썸네일 이미지 로드 | 600/600 (100%) | 실패율 0.6% 미만 |
| 갤러리 첫 장 로드 (보유 표본 455개) | 455/455 (100%) | 실패율 0.8% 미만 |
| 판매처 유효 (상품 API 정상 응답) | 600/600 (100%) | 실패율 0.6% 미만 |
| **판매중 (SALE + 재고 있음)** | **593/600 (98.8%)** | ±0.9%p |
| 판매 불가 (품절 5 · 판매중지/SOLDOUT 유형 포함 총 7) | 7/600 (1.2%) | |
| **가격 일치 (DB `price_final` = 현재 쿠폰 포함 최종가)** | **561/600 (93.5%)** | ±2.0%p |

- 가격이 변한 6.5%(39건)의 편차는 중앙값 14.3%, 90분위 37.2%, 최대 248.5%. 대부분 인상 방향(수집 시점 할인이 끝난 것으로 추정).
- 측정 과정 기록: 처음에 라이브 `salePrice`(쿠폰 미적용가)와 비교해 일치율이 75.2%로 나왔으나, 불일치 149건을 재검증한 결과 110건은 `finalPrice`(쿠폰 포함가)와 정확히 일치 — DB의 `price_final`은 쿠폰 포함 최종가에 대응함을 확인하고 보정했다.
- 표본 100% 통과 항목은 "실패가 0"이 아니라 "표본에서 실패를 못 봤다"는 뜻이다(단측 95% 상한: 실패율 0.6% 미만).

## 4. 노출 가능 조건 후보와 적용 시 상품 수

| 조건 | 상품 수 | 비율 | 용도 |
|---|---:|---:|---|
| A. 썸네일+가격+제목 | 226,319 | 100.0% | 비회원 피드 최소 조건 |
| B. A + 성별 보유 | 224,408 | 99.2% | 성별 필터만 쓰는 경우 |
| C. B + 사이즈 판정 가능 | 162,735 | 71.9% | 회원 자격 필터(PRD 요구) |
| 참고: A + 갤러리 보유 | 173,059 | 76.5% | 상세 화면 슬라이드 품질 |

갤러리는 노출 차단 조건으로 두지 않는 것을 전제로 했다(갤러리 없으면 썸네일 1장만 보여주기로 상세 화면 계획에서 이미 결정).

## 5. Gate 0 통과 기준 제안 (제품 책임자 결정 대상)

측정 결과만 보면 Gate 0 데이터 항목("실제 총량과 필수 필드 커버리지 확인")의 사실 확인은 끝났고, 수치도 양호하다. 결정이 필요한 것은 아래 세 가지다.

### 결정 1 — 노출 가능 조건 확정

제안: **비회원 피드 = 조건 A**(썸네일·가격·제목, 226,319개) + 깨진 1행(goods_no 7022683) 제외. **회원 개인화 피드 = 조건 C**(성별+사이즈 판정 가능, 162,735개). PRD의 "자격 미확인 상품은 회원 피드 제외" 원칙을 그대로 적용한 것.

- 대안: 회원 피드도 성별만 필터(조건 B, 224,408개)로 시작하고 사이즈 필터는 사이즈 정규화 품질을 더 올린 뒤 적용.

### 결정 2 — 사이즈 28% 결손의 취급

162,735개(71.9%)면 티셔츠 단일 카테고리 무한 피드의 모수로 부족하지 않아 보이나, 이는 판단이지 측정이 아니다. "회원 피드 모수 16.3만 개로 충분한가"를 제품 책임자가 결정해야 한다. 부족하다고 판단하면 선택지는 ① 사이즈 정규화 규칙 고도화(옵션 API 재조회) ② 회원 필터를 성별만으로 완화.

### 결정 3 — 가격·판매 상태 신선도 기준

수집 이틀 만에 가격 6.5% 변동·판매 불가 1.2%다. 시간이 지날수록 나빠지므로, MVP 사용자 테스트 전에 다음 중 하나가 필요하다.

- ① 테스트 직전 가격·판매 상태만 전수 재수집(전수 22.6만 × 상품당 1콜, 동시 6 기준 반나절 수준으로 추정)
- ② 주기적 갱신 파이프라인(별도 작업으로 설계)
- ③ 허용 오차를 정하고 그대로 노출(예: "가격 불일치 10% 미만이면 허용" — 단, 사용자 신뢰 리스크는 가드레일 지표로 감시)

제안: Gate 0 시점에는 ①(테스트 직전 1회 재수집)로 충분하고, ②는 Gate 1 진입이 결정된 뒤 설계.

### 통과 판정 제안

다음을 만족하면 Gate 0 데이터 항목 통과로 제안한다: ⓐ 결정 1~3이 내려짐 ⓑ 노출 조건을 적용한 읽기 전용 뷰가 만들어짐 ⓒ 뷰 기준 상품 수가 위 표와 일치함.

## 부록: 방법

- 전수 집계: Supabase `c_goods`에 직접 SQL (2026-08-14).
- 표본: `title`이 있는 상품에서 무작위 600개. 각 상품에 대해 ① 썸네일 GET ② 갤러리 첫 장 GET(보유 시) ③ 상품 상세 API(`goods-detail.musinsa.com/api2/goods/<번호>`)로 유효·판매유형·품절·현재가 확인. 동시 6 이하, 상품당 0.3초 간격.
- 사이즈 정규화 확장 규칙: 표준 문자(XXS~4XL·FREE·OS·F), `^`·`_` 구분자 양쪽 토큰, 괄호 속 치수, 한국 치수 80~120(5단위).
