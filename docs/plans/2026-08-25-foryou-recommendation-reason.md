# FOR YOU 카드에 추천 이유 한 줄을 붙인다

- 작성일: 2026-08-25
- 상태: 구현 완료 — 실행 계획은 `docs/superpowers/plans/2026-08-25-foryou-recommendation-reason.md`(진행 기록 포함)

## 무엇을 / 왜

강사 피드백 — "6주 동안 4명이서 한 것치고는 약하다"는 지적이 있었고 AI 관련해서
눈에 띄는 새 기능을 바라는 뉘앙스였다(2026-08-24, 사용자 전언).

이 저장소엔 이미 임베딩 모델 비교(`docs/atee/foundation/embedding-model-bakeoff.md`),
큐레이션 벡터 랭킹, 성별 기반 개인화 등 상당한 개인화 작업이 있지만 화면에는 순서만
바뀔 뿐 "왜 이게 나한테 떴는지"가 전혀 드러나지 않는다. 그래서 이미 있는 개인화
근거를 사용자에게 문장으로 보여주는 기능을 첫 후보로 잡았다.

시간 여유가 이번 주 며칠뿐이라 챗봇 같은 무거운 대화형 기능은 접고 지금 있는
개인화 신호를 문장으로 바꿔 보여주는 쪽으로 범위를 좁혔다.

## 결정 경위

처음엔 "카드가 보일 때마다 실시간으로 LLM을 불러 문구를 만든다"로 설계하다가,
큐레이션 자체가 64장으로 고정된 데이터라는 지적을 받고 뒤집었다. 사용자마다 다른
큐레이션이 뜨는 것이지, 큐레이션 자체의 내용은 안 바뀐다 — 그러면 문구도 큐레이션당
한 번만 만들어 두면 충분하고 매 조회마다 LLM을 부를 이유가 없다.

그 결과 **런타임에 LLM API를 부르는 서버 라우트가 통째로 없어졌다.** 배치 스크립트
한 번으로 64장 각각에 문구를 채워 넣고 화면은 그 저장된 문구를 꺼내 보여주기만
한다.

## 범위

- 대상 화면: FOR YOU 모자이크 피드 카드만. 큐레이션 상세 페이지는 이번 범위 밖.
- 문구가 뜨는 조건: 그 카드가 **키워드 근거**(내가 최근 반응한 상품 제목이 그
  큐레이션의 조건 키워드에 걸림)로 순위가 올라간 경우만. 벡터 유사도로만 뜬 카드는
  문구를 보여주지 않는다 — 어떤 근거로 맞았는지 구체적으로 말할 수 없는 걸
  지어내지 않기 위해서다.
- 비회원, 개인화가 전혀 안 걸린 방문은 지금처럼 문구 없이 기본 순서 그대로.

## 흐름

1. 큐레이션 64장 각각에 대해, 그 큐레이션의 조건(제목·소개문단·조건 키워드)을
   근거로 "최근 관심 보인 것과 왜 맞는지" 한 줄을 LLM으로 만든다. 한 번만 돌리는
   배치 작업이고, 사람이 만든 결과를 한 번 훑어보고 확정한다(64줄이라 검토 부담이
   크지 않다).
2. 확정된 문구를 큐레이션 데이터에 필드로 추가해 기존 생성기 산출물과 같이
   화면까지 흘러가게 한다.
3. 화면에서 카드의 순위가 키워드 근거로 매겨졌을 때만, 저장된 문구를 그 카드에
   보여준다. 근거가 없거나(벡터만) 개인화가 안 걸렸으면 문구 자리를 그냥 비운다.

## 완료 기준

- 큐레이션 데이터 파일에서 64장 전부 문구 필드가 채워져 있는 게 확인된다.
- 실제 화면에서, 키워드 근거로 개인화된 카드에 문구가 뜨는 걸 눈으로 확인한다.
- 벡터 유사도로만 뜬 카드, 개인화 안 걸린 카드에는 문구가 안 뜨는 걸 확인한다.

## 안 하는 것

- 실시간 LLM 호출, 그걸 위한 서버 API 라우트, 런타임 API 키 관리 — 문구가 전부
  배치로 미리 만들어지므로 필요 없다.
- 문구 캐싱 인프라 — 애초에 실시간 호출이 없으니 캐시할 대상이 없다.
- 벡터 유사도만으로 뜬 카드에 대한 문구.
- 큐레이션 상세 페이지 노출.

## 미정

- **LLM 모델** — Haiku 4.5로 하자는 데는 합의됐다. 배치 스크립트를 실제로 짤 때
  확정한다.
- **문구 필드 검토 방식** — 64줄을 사람이 전부 훑을지, 애매한 것만 짚어줄지는
  실제 초안이 나온 뒤 정한다.
