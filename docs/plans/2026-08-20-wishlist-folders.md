# 보관함 폴더 — 계획 (2026-08-20)

## 결정된 것 (질문 단계 답변)

- 하트 탭(미찜) = **매번 바텀시트**에서 폴더를 골라 담는다. 시트를 그냥 닫으면 찜되지 않는다.
- 채워진 하트 재탭 = **즉시 해제** (시트 없음).
- 기존 찜과 폴더 미지정 찜은 **기본 폴더** 소속으로 본다. 기본 폴더는 이름 변경·삭제 불가.
- 이번 조각 범위: 폴더 만들기·담기·보기 + **이름 바꾸기 + 삭제**(삭제 시 찜은 기본 폴더로 이동). 찜을 다른 폴더로 옮기기는 다음 조각.
- 새 폴더 만들기는 어디서든 **그 자리 인라인 입력** (화면 전환 없음).
- 보관함 첫 화면은 **폴더 그리드(한 줄 2개)**. 타일은 최근 찜 썸네일이 겹쳐 쌓인 모양, 마지막 타일은 + (새 폴더).
- 데이터 모델: 찜 하나 = 폴더 하나. 폴더 테이블 + 찜 행에 폴더 참조 열(비면 기본 폴더). Cosmos식 다대다는 기각 — 해제 의미가 모호해지고 지금 필요 없음.

## 전제

- 찜은 계정 전용(서버 저장)이므로 폴더도 계정 전용이다. 비회원 흐름 변화 없음.
- 서버 계약(SQL RPC)과 클라이언트는 원자적으로 함께 바뀌는 계약이므로 한 조각으로 다룬다(AGENTS 작업 단위 규칙).
- 기존 도구 조사: 시트·그리드는 이미 이 repo의 자체 패턴(상세 오버레이·masonry)이 있어 외부 라이브러리를 들이지 않는다. 서버는 기존 authed RPC 패턴 재사용.

## 단계

### 1. 서버 계약 (마이그레이션 + 검증)

- 폴더 테이블(계정 소속, 이름, 생성 시각)과 찜 행의 폴더 참조 열을 추가한다. 테이블 직접 접근은 막고 RPC로만 연다(기존 찜과 동일한 방식).
- RPC: 폴더 목록 / 만들기(개수 상한) / 이름 바꾸기 / 삭제(안의 찜을 기본으로 이동). 찜 담기는 폴더 인자를 받는 판을 추가하되 **기존 인자 없는 판을 유지**해 배포 사이 구간에도 옛 클라이언트가 깨지지 않게 한다. 찜 목록 반환에 폴더 참조를 더한다(반환형 변경 절차는 backend/README의 drop-먼저 규칙을 따른다).
- 마이그레이션은 재실행 가능하게 쓴다.
- **완료 기준:** 빈 Postgres에서 도는 pytest가 ①권한 행렬(비로그인 호출 거부) ②폴더 상한 ③삭제 시 찜이 기본으로 이동 ④계정 삭제 연쇄를 통과한다. 공유 DB에 적용 후 기존 찜 목록 조회가 여전히 동작한다.

### 2. 프론트 데이터 층

- 도메인에 폴더 타입과 "폴더별 묶기·미리보기 썸네일 고르기" 순수 로직을 추가하고 테스트를 쓴다.
- 계정 찜 공유 저장소가 폴더 목록도 함께 들도록 확장하고, RPC 호출 함수를 추가한다.
- **완료 기준:** vitest 통과. 로그인 상태에서 폴더 만들기 → 새로고침해도 폴더가 남아 있다.

### 3. 담기 바텀시트

- 하트 탭(미찜)에 시트를 연결한다: 폴더 목록(겹침 썸네일 미니·이름·개수) → 탭하면 담기고 닫힘. 목록 끝 "새 폴더" 행은 인라인 입력으로 만들면서 바로 담는다. 시트 밖 탭/닫기는 찜 없음. 채워진 하트는 기존대로 즉시 해제.
- **완료 기준:** 상세에서 하트를 누르면 시트가 뜨고, 폴더를 고르면 하트가 채워지며 보관함 해당 폴더에 상품이 보인다. 시트를 그냥 닫으면 하트가 비어 있다.

### 4. 보관함 폴더 그리드 + 폴더 상세

- 보관함 첫 화면을 폴더 그리드(2열)로 바꾼다: 겹침 썸네일 타일 + 이름·개수, 마지막에 + 타일(인라인 입력). 폴더를 누르면 그 폴더의 2열 masonry 상세로 들어간다(브라우저 뒤로가기로 그리드 복귀). 상세 상단에서 이름 바꾸기·삭제(기본 폴더 제외, 삭제 확인 문구에 "찜은 기본으로 이동" 명시).
- **완료 기준:** 보관함에서 폴더 2열 그리드가 보이고, 타일에 겹친 썸네일과 개수가 맞게 나온다. 폴더 상세에서 이름을 바꾸면 그리드에 반영되고, 삭제하면 안의 찜이 기본 폴더에 나타난다.

### 5. 검증·마무리

- `npm run check`·vitest·pytest 통과, Aside 브라우저로 3·4단계 완료 기준 재연.
- Codex 교차 리뷰 1회 → 지적 등급 매겨 사람 결정 → 반영.
- **완료 기준:** CI 초록불 PR.

## 확정된 값 (구현 중 결정)

- 폴더 개수 상한 20개, 이름 길이 1~24자(공백 다듬은 뒤). 서버(RPC)와 화면 입력란이 같은 값을 쓴다.
- 같은 계정 안 같은 이름 폴더는 서버 unique 색인이 거부하고 화면이 문구로 알린다.
- 이미 찜한 상품을 다른 폴더로 다시 담으면 "옮기기"로 동작한다(서버·화면 동일).
