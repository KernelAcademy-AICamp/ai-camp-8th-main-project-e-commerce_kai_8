# MVP 사용 경험 인터뷰 계획

> 작성 2026-08-18 · 상태: **초안(계획 규칙 2단계)** — 사람 검토 전
> 근거 문서: [PRD 11장 Gate 0](../atee/living/prd.md) · [기회·타깃·JTBD 다음 단계](../atee/foundation/problem-target-jtbd.md) · [결정 기록 O-24·O-29·O-30](../atee/living/decision-log.md)

aTee MVP를 참여자에게 직접 쓰게 한 뒤, 그 경험을 대면 인터뷰로 듣는다. PRD의 **Gate 0**(설명 없이 핵심 조작이 되는가)을 판정하고, 동시에 **첫 가치 반응**(처음 본 사람이 이걸 뭐라 이해하고 얼마나 계속 보는가)을 관찰한다.

---

## 0. 이 테스트가 답하는 것과 답하지 못하는 것

먼저 못 하는 것을 잘라둔다. 섞으면 판정이 흐려진다.

| 질문 | 이번 테스트로 | 이유 |
|---|---|---|
| 설명 없이 조작할 수 있는가 | **판정한다** | PRD Gate 0 그대로 |
| 처음 본 사람이 이걸 뭐라고 이해하는가 | **관찰한다** | 첫인상 발화 |
| 멈추지 않고 계속 보는가 | 1회 세션 안에서만 관찰 | 습관·재방문은 1회로 못 봄 |
| 내 취향으로 변한다고 느끼는가 | **못 한다** | 장기 프로필은 세션 종료 후 반영(O-29). 한 자리 세션으로는 원리상 안 나옴 |
| D7 자발적 재방문율 | **못 한다** | Gate 1 대조 실험의 몫 |
| 무신사 대비 더 나은가 | **못 한다** | Gate 2의 몫 |

세션 중 "개인화가 잘 되던가요?" 류 질문은 **묻지 않는다.** 없는 체감을 질문이 만들어낸다.

## 1. 합의된 조건

| 항목 | 결정 |
|---|---|
| 판정 대상 | 조작(Gate 0) + 첫 가치 반응 함께 |
| **세션 길이** | **30분 이내** |
| **진행 안** | **A안(조작 우선)** / **B안(경험 우선)** 2종 작성 — 어느 쪽을 쓸지 **미정⑧** |
| 순서 | 두 안 모두 **자유 탐색을 먼저**, 과업은 뒤에 (과업을 먼저 주면 이후 탐색이 오염됨) |
| 방식 | 대면 · **녹음만**(화면 녹화 없음) |
| 진행 | 진행자 1 + 기록자 1 |
| 기기 | 우리 폰 또는 참여자 폰 — **미정①** (개발 진행에 따라) |
| 참여자 | 학원 내 다른 사람 (팀원은 참여자 아님) |
| 팀원 역할 | **파일럿 1명** — 가이드 리허설용 |
| 인원 | 5~8명 (PRD Gate 0 기준) — 최종 수 **미정②** |
| 일정 | 개발 마감 ~8/23 · 인터뷰 8/24(월)~ |

### 학원 내부 모집이라 반드시 넣는 장치

참여자 상당수가 "이거 저 사람들이 만든 것"을 안다. 그대로 두면 칭찬만 나온다.

- 진행자는 도입에서 **자기가 만들었다고 먼저 말하지 않는다.**
- 도입 문구에 "**안 되는 데를 찾는 게 목적**이라, 못 쓰겠다는 말이 제일 도움이 됩니다"를 넣는다.
- 칭찬("좋네요", "예쁘네요")이 나오면 **어디가 왜 그랬는지 구체 사례로 되묻고**, 칭찬 문장 자체는 판정 근거로 쓰지 않는다. 기록지에 칭찬 칸을 따로 둬 해석에서 제외한다.

## 2. 착수 조건 (이게 되면 시작)

날짜가 아니라 **동작하는 기능**으로 착수를 판정한다. 실기기(모바일 브라우저)에서 아래가 되면 세션을 시작한다.

| # | 조건 | 안 되면 |
|---|---|---|
| A | 피드 무한 스크롤이 끊기지 않고 이어진다 | **착수 불가** — 이게 제품의 전부 |
| B | 카드를 탭하면 상세가 열리고, 뒤로 가면 이전 스크롤 위치로 돌아온다 | **착수 불가** |
| C | 상세에서 이미지 슬라이드를 넘길 수 있다 | 해당 과업만 제외하고 진행 |
| D | 상세 하단에 닮은 상품이 이어진다 | 해당 과업만 제외하고 진행 |
| E | 찜이 되고 찜 목록에서 보인다 | 해당 과업만 제외하고 진행 |
| F | 판매처로 이동하고 돌아올 수 있다 | 해당 과업만 제외하고 진행 |

**완료 기준:** 위 표에 O/X가 채워진 실기기 확인 기록이 있고, 제외할 과업이 무엇인지 세션 시작 전에 확정돼 있다.

## 3. 단계

### 1단계 — 무엇이 실패인지 먼저 못박는다 (반나절)

세션을 돌리기 전에 채점표를 만든다. PRD가 "통과 수치와 허용 오류는 테스트 시작 전에 확정한다"고 요구한다.

할 일:

1. 관찰할 조작 **10항목**은 [기록지](../atee/research/interview-record-sheet.md)에 확정돼 있다 (피드 스크롤 / 상세 열기 / 상세→피드 복귀 / **복귀 시 스크롤 위치 유지** / 이미지 슬라이드 / 하단 닮은 상품 / 찜 / 찜 목록 / 판매처 이동 / 판매처에서 복귀).
2. 판정은 `○ △ ✕ —` 4단계로 이미 정의했다. 초를 세지 않고 "막힘없이 갔는가 / 멈칫했는가"로 매긴다.
3. Gate 0 **통과선을 숫자로** 정한다. 예: 항목별로 참여자 N명 중 M명 이상이 자유 탐색 구간에서 `○` — **미정③, 사람이 정함**
4. 세션 뒤에 결과를 보고 이 기준을 바꾸지 않는다는 것을 문서에 못박는다.

⚠️ **통과선은 `자`(자유 탐색) 구간의 `○`에만 건다.** A안의 과업 구간 성공은 진행자가 목적을 알려준 뒤의 성공이라 "설명 없이"라는 Gate 0 정의를 만족하지 않는다. 참고 지표로만 집계한다.

**완료 기준:** A4 한 장짜리 채점표가 있고, 진행자와 기록자가 **영상 없이도 같은 O/X를 매길 수 있을 만큼** 정의가 구체적이다. (파일럿에서 두 사람이 따로 매겨 불일치 항목이 있는지 확인)

---

### 2단계 — 가이드와 기록지 만들기 (반나절)

**초안 작성 완료 (2026-08-18).** 세 문서가 있다.

| 문서 | 내용 |
|---|---|
| [A안 진행 가이드](../atee/research/interview-guide-a.md) | 조작 우선형 30분 — Gate 0 판정용 |
| [B안 진행 가이드](../atee/research/interview-guide-b.md) | 경험 우선형 30분 — 첫 가치 반응용 |
| [기록지](../atee/research/interview-record-sheet.md) | A·B 공용. 기록자가 손으로 채우는 종이 |

기록지에 들어간 칸: 헤더(기기·초기화·조건 충족) · 조작 판정 10항목 · 멈춤 로그 · 지속 지표 · 발화 원문 · **칭찬(해석 제외)** · 클로즈 커밋 · **해석(분리)** · 세션 직후 확인.

**완료 기준:** 인쇄해서 들고 갈 수 있는 상태이고, 기록자가 빈 기록지만 보고도 무엇을 채워야 하는지 안다. → **문서는 있으나 "기록자가 보고 채울 수 있는지"는 파일럿 전까지 미검증.**

---

### 3단계 — 파일럿 1건 (팀원, 세션 30분 + 디브리핑 30분)

가이드대로 팀원 1명에게 실제로 돌려본다. 팀원은 이미 화면을 알기 때문에 **조작 데이터로는 쓰지 않고**, 가이드가 굴러가는지만 본다.

보는 것:

- **30분 안에 끝나는가** (두 안 모두 시간이 빡빡하다 — 어느 구간이 밀리는지 본다)
- 참여자가 못 알아듣는 질문이 있는가
- 기록자가 손이 모자라는 구간이 있는가
- 기기 준비·초기화 절차가 실제로 되는가

**완료 기준:** 최소 1개의 문제를 찾아 가이드를 고치고, 가이드에 **버전 번호(v2)를 붙인다.** 이후 세션은 전부 같은 버전으로 돌리고, 중간에 바꾸면 버전을 올려 기록한다. (질문지 버전을 안 남긴 것이 지난 인터뷰의 실패였다)

---

### 4단계 — 모집·스크리닝 (8/24 주 초)

PRD 1차 타깃 조건: 최근 4주 주 1회 이상 모바일 무신사 베스트 탐색 + 장바구니를 호감 상품 보관함으로 사용.

학원 내부에서는 이 조건을 다 채우기 어려울 수 있다. **조건 미충족자를 배제하지 않고, 표기해서 받는다.** 분석에서 충족/미충족을 나눠 본다.

스크리닝은 **말이 아니라 증거로** 한다. "자주 보세요?"는 전부 "네"가 나온다.

| 확인할 것 | 자기보고 대신 |
|---|---|
| 탐색 빈도 | 무신사 앱을 열어 최근 본 상품 / 스크린타임 기록 보여주기 |
| 장바구니를 보관함으로 씀 | 장바구니를 열어 담은 지 2주 넘은 항목이 있는지 |
| 티셔츠 관심 | 최근 주문내역 또는 장바구니 구성 |

증거 확인은 사전 폼으로 미리 받아도 되고, 세션 도입 5분 안에 현장에서 해도 된다. 방법은 열어둔다.

**완료 기준:** 참여자별로 이름·일시·조건 충족 여부(증거 방식 포함)가 적힌 명단이 있고, 세션 일정이 잡혀 있다. **하루 2~3건을 넘기지 않는다.**

---

### 5단계 — 세션 실행 (8/24~8/28)

한 건 **30분**. 상세 구조는 4절, 실물 문안은 [A안](../atee/research/interview-guide-a.md)·[B안](../atee/research/interview-guide-b.md) 가이드.

**완료 기준:** 참여자 1명당 ①녹음 파일 1개 ②채워진 기록지 1장이 남는다. 둘 중 하나라도 없으면 그 세션은 미완으로 표시한다.

---

### 6단계 — 정리와 판정 (8/28~8/29)

1. 녹음을 전사한다(전량 또는 해당 구간).
2. 참여자별로 **발화 / 관찰 / 해석** 3칸 표를 채운다. 섞지 않는다.
3. 채점표에 참여자별 판정을 옮긴다. **`자` 구간과 `과` 구간을 섞지 않는다.**
4. **자발 발견율**(`자` 구간 ○)을 통과선과 대조해 Gate 0 통과·미통과를 판정한다. 유도 성공률(`과` 구간)은 참고로만 붙인다.
5. 비율을 쓸 때는 **분모를 함께 쓴다.** "70%"가 아니라 "7명 중 5명". (지난 인터뷰에서 분모 없는 비율이 근거로 굳어졌던 문제)

**완료 기준:** ①항목별 O/X 표 ②통과·미통과 판정 ③판정마다 근거가 되는 **발화 원문 인용 또는 관찰 기록**이 붙어 있다. 실패·애매한 항목을 표 위쪽에 둔다.

---

### 7단계 — 반영

- Gate 0 **미통과 항목이 있으면** 추천 모델 확대를 멈추고 그 조작부터 고친다 (PRD 규정).
- 결정이 바뀌면 [결정 기록](../atee/living/decision-log.md)에 O-번호로 남긴다.
- PRD Gate 0 문구의 `스타일 계속 탐색`은 O-30으로 전용 버튼이 사라졌으므로 **"상세 하단 닮은 상품 탐색"으로 갱신**한다.

**완료 기준:** 결정 기록에 새 항목이 있거나, "바꿀 것 없음"이 이유와 함께 적혀 있다.

## 4. 세션 구조 — 30분, 두 안

실물 가이드는 별도 문서에 있다. 여기서는 **무엇을 맞바꾸는지**만 적는다.

| 구간 | [A안 — 조작 우선](../atee/research/interview-guide-a.md) | [B안 — 경험 우선](../atee/research/interview-guide-b.md) |
|---|---|---|
| 도입 | 0–3분 | 0–2분 |
| 워밍업 | **없음** — 제품을 만지는 행위로 대체 | 2–8분 **현재 행동 스토리** (데이터 겸용) |
| 자유 탐색 (무설명) | 3–15분 (12분) | 8–18분 (10분) |
| 조작 과업 | 15–22분 (미수행 항목만) | **없음** |
| 인터뷰 | 22–28분 (6분) | 18–28분 (10분) |
| 클로즈·커밋 | 28–30분 | 28–30분 |

### 무엇을 얻고 무엇을 잃는가

| | A안 | B안 |
|---|---|---|
| Gate 0 조작 항목 커버리지 | **거의 전부** (과업으로 채움) | 참여자가 만진 것만 — **공백 생김** |
| 발화 품질 | 낮음 (인터뷰가 22분에 시작) | **높음** (8분에 이야기 모드 진입) |
| 무신사 대비 비교 | 불가 (기준선 없음) | **가능** |
| 30분 초과 위험 | 중간 (과업이 밀리면 인터뷰가 사라짐) | 낮음 |

### 두 안 공통 규칙

- **자유 탐색을 설명 없이 먼저** 한다. 과업이나 설명이 앞서면 이후 탐색을 판정에 못 쓴다.
- 참여자가 막혀도 **돕지 않는다.** 2분 이상 완전히 멈추면 그 항목은 `✕`.
- **"이제 그만하셔도 돼요"라고 먼저 말하지 않는다.** 스스로 멈춘 시각이 유일한 지속 신호다.
- 클로즈에서 의향이 아니라 **다음 세션 날짜**를 요청한다. 날짜를 안 잡으면 미수락으로 집계.
- 개인화 체감과 D7 재방문은 **묻지도 판정하지도 않는다.**

### 30분이라 생긴 제약

좋은 발화는 참여자가 짧은 답에서 이야기로 넘어간 뒤에 나온다. 30분에서는 그 구간이 20분 남짓뿐이라 **워밍업을 없앨 수 없다.** 두 안은 워밍업을 없애는 대신 **데이터가 되는 워밍업**으로 바꾼 것이다 — A안은 제품 조작으로, B안은 현재 행동 스토리로.

## 5. 기기 처리 (경로별)

| 경로 | 절차 | 주의 |
|---|---|---|
| **참여자 폰** | 브라우저로 주소 접속 | 기기 ID가 참여자에게 남아 며칠 뒤 재방문까지 이어 볼 수 있음. 시크릿 모드면 안 남으니 확인. 종료 시 설정 화면의 삭제 수단을 안내한다 |
| **우리 폰** | 참여자마다 **초기화 후 시작** | 초기화하지 않으면 앞 참여자의 탐색 이력이 다음 사람 피드에 섞인다. 초기화 방법과 "초기화됐음을 눈으로 확인하는 절차"를 파일럿 전에 확정 — **미정⑤** |

어느 경로든 세션 시작 전에 **초기 상태가 같은지**를 기록지에 O/X로 남긴다.
