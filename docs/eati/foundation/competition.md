# eati 경쟁·대안 분석

> 조사일: 2026-08-12 · 범위: 모바일 티셔츠 발견과 개인화 탐색 · 공식 자료 중심

## 분석 질문

> 검색 목적이 뚜렷하지 않은 사용자가 많은 이미지를 부담 없이 훑으면서, 대중의 취향이 아니라 자신의 반복 행동에 맞는 상품과 새로운 디자인을 계속 발견하게 하는 대안은 무엇인가?

공개 자료는 기능과 회사 전략을 확인하는 데만 사용한다. 각 서비스의 전환 효과와 국내 사용자 만족을 eati의 근거로 간주하지 않는다.

## 경쟁·대안 지도

| 대안 | 사용자가 얻는 가치 | 강점 | eati가 검증할 차이 |
|---|---|---|---|
| 무신사 베스트 + 장바구니 | 많은 사람이 본 상품을 빠르게 훑고 호감 상품을 보관 | 익숙함, 넓은 티셔츠 카탈로그, 거래 정보와 구매 연결 | 집단 순위가 아니라 개인의 반복 탐색에 따라 노출 구성이 달라지는가 |
| 일반 개인화 추천 피드 | 과거 클릭·구매와 비슷한 상품을 수동 입력 없이 확인 | 행동 기반 관련성, 낮은 사용 비용 | 유사 상품 반복을 넘어 부분 일치·반대 스타일·신상품을 의도적으로 섞는가 |
| 무신사 AI 트렌드 큐레이션 | 검색 없이 플랫폼이 고른 트렌드 테마를 탐색 | 국내 패션 데이터와 최신 트렌드, 낮은 입력 부담 | 플랫폼 중심 트렌드보다 개인의 장기 취향과 현재 세션 방향을 우선하는가 |
| 무신사×카카오, Daydream | 상황과 취향을 대화나 이미지로 설명해 추천받음 | 모호한 목적을 언어로 구체화하고 질문을 반복 | 취향을 설명하지 않고 이미지를 훑는 행동 자체가 입력이 되는가 |
| Google Lens, Amazon Lens/More Like This | 기준 이미지와 닮은 구매 가능 상품을 빠르게 찾음 | 강한 시각 기준, 풍부한 상품·가격 정보 | 하나의 기준에 수렴하지 않고 탐색 방향과 새로움의 비율이 계속 변하는가 |
| Pinterest | 이미지를 보며 취향을 형성하고 저장·쇼핑 | 시각적 발견, 개인화, 저장과 영감 범위 | 티셔츠 실제 상품과 가격에만 집중한 더 좁고 구매 인접한 경험을 만드는가 |
| Cosmos | 무한 이미지 캔버스에서 영감을 발견하고 저장 | 밀도 높은 시각 탐색과 컬렉션 | 영감 이미지가 아니라 실제 티셔츠 카탈로그와 개인 행동 학습을 결합하는가 |

## 주요 제품별 확인 사항

### 무신사

- 2026년 6월 특정 목적 없이 트렌드와 스타일을 찾는 ‘발견형 소비자’를 명시하고 AI 트렌드 큐레이션을 모자 카테고리에 도입했다. [공식 발표](https://newsroom.musinsa.com/newsroom-menu/2026-0603)
- 2026년 3월에는 카카오톡 대화에서 TPO, 날씨, 브랜드 취향을 받아 상품·코디·후기를 추천하는 서비스를 출시했다. [공식 발표](https://newsroom.musinsa.com/newsroom-menu/2026-0324)
- **해석:** 국내 대형 플랫폼도 목적 없는 발견을 별도 문제로 본다. 반면 카탈로그·구매 데이터·거래 경험을 가진 무신사가 개인화 피드를 강화하면 eati의 기능 차이는 쉽게 좁아질 수 있다.

### Daydream

- 자연어 대화와 이미지 업로드로 여러 브랜드 상품을 찾고, 판매자 스토어에도 같은 경험을 제공한다. [공식 파트너 페이지](https://partners.daydream.ing/)
- **해석:** ‘AI가 취향을 이해하는 쇼핑’만으로는 차별화되지 않는다. eati의 주장은 대화 품질이 아니라 설명 없이 반복되는 이미지 탐색을 학습 인터페이스로 만든다는 데 있다.

### Google Lens와 Amazon

- Google은 사진·화면 속 상품에서 유사 상품, 가격, 리뷰, 판매처로 연결한다. Google은 월간 약 200억 건의 Lens 검색 중 20%가 쇼핑 관련이라고 공개했다. [Google Lens 공식 글](https://blog.google/products-and-platforms/products/shopping/visual-search-lens-shopping/)
- Amazon은 이미지+텍스트 보정, 시각적 필터, 스타일 콜라주, 상품별 `More Like This`를 제공한다. [Amazon 공식 글](https://www.aboutamazon.com/news/retail/visual-search-shopping-features)
- **해석:** 기준 상품에서 유사 상품으로 가는 기능은 기본 기대치다. eati는 유사도 수렴뿐 아니라 일부 일치와 반대 제안을 유지해야 한다.

### Pinterest와 Cosmos

- Pinterest는 사용자가 말로 설명하지 못해도 이미지를 보며 취향을 좁히고 저장·쇼핑한다고 설명하며, 이미지 일부에서 유사·구매 가능 상품을 찾는 기능을 제공한다. [제품 설명](https://business.pinterest.com/en-IN/how-pinterest-works/) · [비주얼 검색 도움말](https://help.pinterest.com/en/article/use-visual-search-features)
- Cosmos는 색·키워드·이미지 검색, 무한 이미지 캔버스, 저장과 컬렉션을 제공한다. [App Store 제품 페이지](https://apps.apple.com/us/app/cosmos-search-discover/id1577975475)
- **해석:** 무한 시각 탐색과 취향 형성 자체는 새로운 개념이 아니다. eati는 실제 티셔츠, 가격, 착용 가능 조건, 판매처 이동과 결합할 때만 별도 가치를 갖는다.

## 상호작용 참고와 경쟁의 구분

- **인스타그램형 세로 피드:** 위에서 아래로 습관적으로 탐색하는 방향성의 참고다.
- **애플 사진첩형 밀도 전환:** 핀치로 이미지 전수조사와 집중 보기를 오가는 조작의 참고다.
- 이 둘은 eati의 경쟁 우위가 아니다. 익숙한 조작을 빌려 개인화 효과를 시험하는 UI 가설이다.

## 잠정 포지셔닝

> eati는 검색창이나 대중 순위 없이, 실제 티셔츠 이미지와 가격을 애플 사진첩처럼 훑는 동안 사용자의 장기 취향과 현재 탐색 방향을 학습하고 관련성·새로움의 비율을 자동 조절하는 개인화 무한 쇼핑 PWA다.

### 포지셔닝 축

- 집단 인기보다 개인의 반복 행동
- 취향 직접 설정보다 탐색을 통한 암묵적 학습
- 유사 상품 수렴보다 익숙함·경계·반대 제안이 공존하는 포트폴리오
- 리뷰·랭킹·프로모션보다 이미지와 가격에 집중
- 자체 거래보다 발견과 판매처 연결에 집중

이 조합은 아직 방어 가능한 우위가 아니다. 같은 UI의 비개인화 피드보다 재방문을 높이지 못하면 개인화 포지셔닝을 폐기하거나 재설계한다.

## 경쟁 분석이 만드는 요구사항

- 베스트 목록처럼 바로 훑을 수 있어야 하며 검색이나 가입을 진입 장벽으로 두지 않는다.
- 가입 전에도 비개인화 피드로 핵심 조작을 체험하게 한다.
- 개인화는 사용자가 이전 선택과 닮은 상품 구성을 보고 체감할 수 있어야 한다.
- 동일 상품·스타일 반복을 막고 부분 일치·반대 스타일·신상품 노출을 유지한다.
- 찜한 상품과 탐색 위치를 잃지 않으며 외부 판매처 방문 후에도 복귀한다.
- 카드 크기·위치·열 수가 클릭 확률에 미친 영향을 기록해 취향으로 오학습하지 않는다.
- 스폰서 상품과 수익 최적화는 가치 검증 단계에서 제외한다.

## 조사 한계

- 공식 발표는 기능 존재와 회사 전략의 자료이며 효과에 대한 독립 평가가 아니다.
- 각 제품을 동일한 티셔츠 과업과 같은 사용자 집단으로 직접 비교하지 않았다.
- 국내 타깃의 규모, 획득 비용, 장기 유지율, 지불 의향은 알 수 없다.
- 경쟁 기능은 빠르게 변하므로 폐쇄 베타 전 다시 확인한다.
