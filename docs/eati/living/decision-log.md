# eati 결정 기록

> 최종 수정: 2026-08-13 · 상태: 현재 제품 결정

## 결정 목록

| ID | 결정 | 근거와 의미 |
|---|---|---|
| O-01 | eati는 기존 `search-by-llm`과 별도 제품이다. | 자연어 검색을 개선하는 기능이 아니라 검색 없이 탐색하는 별도 경험이다. |
| O-02 | 문제를 ‘쇼핑 피로’로 정의하지 않는다. | 인터뷰 참여자는 베스트 목록 반복 스크롤에 뚜렷한 불만을 표현하지 않았다. eati는 불편 제거가 아니라 개인화된 새 가치를 검증한다. |
| O-03 | 1차 타깃은 매주 무신사 베스트를 훑고 장바구니에 담아두었다가 구매하는 사용자다. | 기존 LLM 검색 인터뷰 5~10명 중 약 70%에서 관련 패턴이 회고됐다. |
| O-04 | 완료·후보 압축 없이 무한 탐색을 유지한다. | 2~5개 후보를 남기는 목표는 제품 책임자의 의도와 다르므로 폐기했다. |
| O-05 | 2차원 궤도형 공간 대신 세로형 모자이크 피드를 사용한다. | 인스타그램처럼 위에서 아래로 탐색한다. |
| O-06 | ~~기본 3열, 축소 5열 이미지 전용, 확대 2열 이미지+가격을 사용한다.~~ | 2026-08-13 O-22로 대체됨. |
| O-07 | ~~탭은 바텀 시트를 열고, 상세의 `이 스타일로 계속 탐색`이 이후 피드 방향을 바꾼다.~~ | 2026-08-13 O-23으로 대체됨. |
| O-08 | 피드 카드는 이미지와 가격에 집중한다. | 브랜드·평점·리뷰·인기 신호보다 디자인과 지불 가능성을 먼저 보게 한다. 가격은 이미지 위 배지로 노출한다. |
| O-09 | 장기 취향과 현재 세션 방향을 분리한다. | 세션 선택은 빠르게 반영하되 장기 취향을 소량 유지하고 단발 행동이 프로필을 덮지 않게 한다. |
| O-10 | 유사·최근 관심·부분 일치·반대 스타일을 모두 포함하고 비율을 자동 조절한다. | eati는 닮은 상품만 보여주는 추천기가 아니라 취향 경계를 계속 시험하는 발견 시스템이다. |
| O-11 | 개인화는 반복 탐색, 스타일 계속 탐색, 찜, 판매처 이동을 사용한다. | 찜과 판매처 이동은 강한 긍정 신호지만 실제 구매로 간주하지 않는다. 명시적 부정 신호는 후속 단계다. |
| O-12 | 비회원은 비개인화 탐색을 먼저 경험하고 회원만 장기 개인화를 받는다. | 가입 전에 가치를 보여주며, 가입 전 임시 이력은 계정으로 승계한다. |
| O-13 | 가입 시 연령대·성별·키·사이즈를 받는다. | 성별·키·사이즈는 착용 자격, 연령대는 세그먼트 분석에 사용한다. |
| O-14 | 모바일 우선 PWA로 제공한다. | 설치 없이 진입하고 설치 후 앱처럼 재방문한다. 제스처에는 항상 명시적 대체 동작을 제공한다. |
| O-15 | 초기 카탈로그는 현재 DB의 무신사 티셔츠 약 22만 개로 제한한다. | 수량은 사용자 제공 정보이며 필드 커버리지와 실제 총량은 MVP 전 감사가 필요하다. |
| O-16 | eati는 상세 화면까지만 담당하고 거래는 외부 판매처로 연결한다. | 판매처 이동은 구매 의도 대리 지표이며 실제 결제·매출이 아니다. (2026-08-13 바텀 시트 → 상세 화면 표현 갱신) |
| O-17 | 초기 성공은 D7 재방문과 유효 탐색으로 판단한다. | 첫 목표는 가치 검증이며 수익화는 범위 밖이다. 체류시간은 혼란 가드레일과 함께 본다. |
| O-18 | 같은 eati UI의 비개인화 피드와 개인화 피드를 먼저 비교한다. | UI의 신기함과 개인화 효과를 분리한 뒤 무신사 베스트와 전체 경험을 비교한다. |
| O-19 | 유기적 재방문 확인 전 푸시를 실험에 섞지 않는다. | 가치 확인 뒤 충분히 개인화된 회원에게 동의를 받아 푸시의 증분 효과를 별도로 측정한다. |
| O-20 | 광고·제휴·유료 기능 없이 가치 검증에 집중한다. | 수익 최적화가 추천 신뢰와 초기 학습을 왜곡하지 않게 한다. |
| O-21 | 서비스명을 `eati`로 확정한다 (2026-08-13, 임시명 Orbit 폐기). | 미국 슬랭 "eat"("eat, i")의 어감과 "이 티(셔츠)"라는 한국어 중의적 의미를 함께 담는다. |
| O-22 | 핀치 밀도 전환 없이 2열 고정 masonry(카드 세로 길이 가변) 피드를 사용한다 (2026-08-13). | 제품 책임자가 Cosmos형 무한 스크롤 경험으로 확정했다. O-06의 5·3·2열 핀치 전환을 대체한다. |
| O-23 | 탭은 바텀 시트 대신 카드가 확대되는 전환의 상세 화면을 열고, 상품 이미지들을 슬라이드로 본다 (2026-08-13). | 단일 탭 상세 원칙은 유지하되 형태를 확대 전환 상세로 바꿨다. 상세의 `이 스타일로 계속 탐색`이 피드 방향을 바꾸는 역할과 길게 누르기 단축 동작도 유지한다. 뒤로 가면 카드로 줄어들며 피드 스크롤 위치로 복귀한다. |

## 대체된 결정

| 이전 방향 | 대체 이유 | 현재 결정 |
|---|---|---|
| 후보 2~5개를 남기고 선택을 끝냄 | 제품 책임자는 완료보다 무한 탐색을 원함 | O-04 |
| 상품이 중심이 되고 주변 궤도가 재배치됨 | 세로 이미지 전수조사 습관과 맞지 않음 | O-05, O-23 |
| 첫 탭은 재배치, 두 번째 탭은 상세 | 재탭 규칙이 숨겨져 발견하기 어려움 | O-23 |
| 후보·맥락 손실이 핵심 고통 | 인터뷰에서 현재 방식의 불만이 확인되지 않음 | O-02 |
| 그리드보다 공간 지도가 우월한지 검증 | 현재 제품은 공간 지도가 아님 | O-05, O-18 |
| 핀치로 5·3·2열 밀도를 전환하고 5열에서 가격을 숨김 | 제품 책임자가 2026-08-13 Cosmos형 2열 고정 masonry로 단순화 결정 | O-22 |
| 탭이 피드 위에 바텀 시트를 엶 | 제품 책임자가 2026-08-13 카드 확대 전환의 상세 화면(이미지 슬라이드 포함)으로 변경 | O-23 |
